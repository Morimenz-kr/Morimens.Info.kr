# 도감 필터용 게임 원본 아이콘

## 출처와 크기

2026-11-11 설치된 Windows 클라이언트의 아틀라스에서 직접 추출했다. 버전은 res18 / build11이다. 이미지별 원본 스프라이트 이름, 아틀라스, 번들 SHA-256, 크기, 연결한 속성·상태·키워드 식별자는 [manifest.json](manifest.json)에 기록한다.

기존 images/keyword-icons/reference의 위키 15px 썸네일과 다르다. 원본 Sprite의 픽셀·알파를 그대로 저장했으며 리사이즈·샤프닝·벡터화·AI 확대를 적용하지 않았다. 필터에서는 가로세로 1.25rem 안에 비율을 유지하여 표시한다. 원본이 작은 아이콘은 큰 화면 확대에서도 무한히 선명한 벡터가 되지는 않는다.

## 연결 기준

- 영역 숙련·피해 증폭·크리티컬 등은 ActorAttrType.Icon의 실제 속성 표시 아이콘을 사용한다.
- 은열쇠 에너지·광기는 WordsEffectConfig의 전용 이미지 연결을 사용한다. 광기의 EnergyIconKeywords를 산출력으로 오인하지 않는다.
- 상태는 State.Icon 또는 전용 키워드의 같은 번호 아이콘을 사용한다. 소모·허무·유지·발견·배아 융합 등은 게임 키워드 설정 자체가 공용 경고 아이콘을 사용한다.
- 사용자 선택에 따라 산출력과 드로우·카드 추가·회수·버리기·비용 감소에 게임의 UI_Comon_Icon_AwakerSkill을 공통 분류 아이콘으로 재사용한다. 게임의 전용 산출력 아이콘이라는 뜻은 아니다. 다른 미확인 항목은 빈 공간만 유지한다.
- 방어막은 경계와 같은 파란 방패를 사용한다. 핏빛 용광로는 UIBloodDrop.BindBloodHeal이 조절하는 Group_Heal/Image_Blood의 붉은 구체 Sprite(UI_Battle_Image_D_Blood_11)를 사용한다. 실제 게임에서는 충전량에 따라 채움 비율과 물결 효과가 변하는 UI이며, 필터에서는 원본 Group_Heal 바탕 위에 구체를 세로·아래 기준 50%로 잘라 표시한다. 프리팹의 350×234 바탕과 128×128 구체 좌표를 동일 비율로 배치하며, 물결 애니메이션·Unity 재질 셰이더는 재현하지 않는다. ScarletBlood 물방울 아이템과는 구분한다.
- 표시 여부를 결정하는 연결표는 js/links.js의 renderDictionaryFilterIcon에 있다. 사용자에게 보이는 한국어 문구를 파일 이름 추측만으로 연결하지 않는다.
