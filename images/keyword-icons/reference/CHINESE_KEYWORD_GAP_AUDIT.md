# 중국 위키 키워드 사전 미등록 대조

- 검사 범위: `신왕·투루`와 사이트 미수록 `카라부`를 제외한 중국 위키 각성체 59명
- 중국 위키에서 실제 `词条` 템플릿으로 사용된 항목: 133종
- 우리 사전과 번역·별칭·숫자형 변형으로 대응됨: 53종
- `db_tooltips.json`에 직접 대응하지 않는 항목: 79종
- 이 문서는 참고 자료이며 사이트와 `db_tooltips.json`에는 아직 반영하지 않는다.

> 주의: 79종은 **사이트에 없는 항목 수가 아니다.** 최초 대조가
> `db_tooltips.json`만을 기준으로 했기 때문에 카드명·파생 카드·효과명으로 이미
> `character_effects.json` 등에 존재하는 항목도 포함한다.

## 사이트 전체 재대조 결론

중국 위키에만 있고 우리 사이트의 각성체·카드·차원 영상·명륜·은열쇠 데이터에는
이름조차 존재하지 않는다고 확정할 수 있는 키워드는 현재 없다.

- `回响`은 우리 데이터의 `메아리`이다.
- `真实伤害`는 노틸라·파인트 문맥에서 우리 데이터의 `고정 피해`와 대응할
  가능성이 높아 별도 신규 키워드로 확정하지 않는다.
- `强制保留`, `旧日余烬`은 신규 침식·로탄 데이터에 각각 `강제 유지`,
  `옛날 잔재`로 이미 등장한다.
- `恐惧之血`, `生殖之血`, `圣洁之子`는 각각 `공포의 피`, `생식의 피`,
  `성결의 자식`으로 이미 존재한다.
- 나머지도 카드 효과명, 선택지명, 영역 효과명 또는 캐릭터 고유 효과명으로
  사이트 데이터에 존재한다. 따라서 아래 목록은 **신규 콘텐츠 목록이 아니라
  툴팁 사전 미등록 후보 목록**으로만 사용한다.

## 2. 고유 카드 키워드로 보이는 검토 후보

기존 규칙상 특성·계령에서 발생한 것이 아니라 카드 본문에 직접 쓰였다면 툴팁 후보가 될 수 있다.

- 회환 계열: `回环`, `轮回之庭`, `未来讴歌`, `负熵`
- 기억·음악 계열: `追忆`, `回环乐音`, `蓄势乐音`
- 화염 계열: `爆炎`
- 혈육 계열: `围猎`, `恐惧之血`, `溃烂之血`, `生殖之血`, `圣洁之子`, `奉献`, `超度`, `救赎`, `残骸`
- 의식·감정 계열: `篡夺`, `蛰伏`, `祭仪`, `「圣礼」`, `坚守自我`, `投身启示`, `「神国幻影」`, `「怒」`, `「哀」`, `「喜」`, `「惧」`, `隐喻`
- 창조물 계열: `创构的白银造物`, `创构的黄金造物`, `创构的刻印`
- 수면·정신 계열: `深眠反击`, `呓语回音`, `催眠脉络`
- 초차원·특수 계열: `相许`, `夺魄`, `羽种`, `奇点折跃`(특이점 도약), `织命`(직명), `无尽线缕`, `奇点棱镜`, `奇点信标`, `超距`, `「黑羽」`

## 3. 시스템 표기 또는 툴팁 비대상으로 보이는 항목

- `超限爆发`, `最终法则`: 카드·성장 시스템 명칭에 가까움.
- `界域精通`: 영역 숙련. 사용자가 광기·산출력 등과 함께 툴팁 비대상으로 지정한 일반 수치 계열.
- `界域效果·混沌`, `界域效果·深海`, `界域效果·血肉`, `界域效果·超维`: 영역 효과 표기.
- `混沌·抑郁&躁狂`, `深海·抑郁&躁狂`, `血肉·抑郁&躁狂`, `超维·抑郁&躁狂`: 24의 영역·인격 분기 표기.
- `奇妙正面效果`, `奇妙负面效果`: 여러 기존 효과를 무작위로 묶은 선택 효과.

## 4. 기존 규칙에 따라 제외할 가능성이 높은 항목

- `「混沌的遗赠」`: 라이커 특성 `승자 독식`의 하위 효과인 `혼돈의 유산`에 대응하므로 제외.
- `篡夺`, `蛰伏`: 골리앗의 `찬탈`, `잠복` 선택 효과로 이미 본문에 분류되어 있으므로 신규 누락 항목에서 제외.

나머지 고유 항목은 카드, 특성, 계령 중 어디서 발생하는지 한국어 원문과 한 번 더 대조한 뒤 포함 여부를 결정해야 한다.

## 5. 누락이 아닌 번역 대응

- `跃迁` = 워프
- `维度穿梭` = 차원이동
- `销毁` = 폐기
- `脆弱` = 손상
- `涡流装填` = 소용돌이 장전
- `梦引` = 꿈의 유혹
- `共感` = 공감
- `命运裁断` = 운명재단
- `奇点折跃` = 특이점 도약
- `织命` = 직명
- `번식광란` 표기는 현재 한국어 기준 `번식 축전`으로 변경됨.
