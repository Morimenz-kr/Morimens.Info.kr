## 상단 조작부와 모바일 귀속 토글 재점검

상단의 표시·DOM·Tab 순서는 **귀속 → 비밀계약 변경 → 전체 초기화**다. 세 조작을 오른쪽으로 정렬하고, 좁은 화면에서는 순서를 유지하며 줄바꿈한다. 부위 옆 버튼은 ‘부위 변경’으로 구분한다. 네이티브 체크 입력에 `role=switch`를 사용하며, 라벨의 조작 영역은 44px 이상이다.

독립 레드팀의 Chrome 모바일 터치 컨텍스트에서 두 편집기 × 7개 조건(320·390·768·1024·1280px, 844×390, 320px 글자 200%)을 검증했다. 오른쪽 정렬·시각 순서·포커스 순서·겹침·잘림·가로 넘침이 모두 통과했다. 라벨 터치·스위치 터치·Space 조작은 각각 한 번만 상태를 바꾸며, 주옵션 4%↔6%와 금색↔회색이 일치한다. 반복 터치로 텍스트가 선택되지 않도록 `user-select:none`을 적용했다.

귀속 변경 직후 새로고침·복사·선택창 취소에서 상태를 유지하고, 전체 초기화 후에는 귀속과 초기화 버튼을 비활성화한다. 실제 계산에서 꺼짐→켜짐→꺼짐을 실행한 시험 파티의 크리티컬 확률은 27→33→27, 영역 숙련은 20→30→20이었고 마지막 전체 속성이 최초 값과 일치했다. 이번 범위에서 새 기능 오류는 발견하지 못했다.
