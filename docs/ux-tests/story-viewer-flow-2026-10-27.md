# 스토리 뷰어의 행동 흐름과 효과 표시 검증

`codex/story-viewer-flow`에서 기존 스토리 뷰어를 보완했다. 메인 병합·푸시·배포는 하지 않았다.

## 표시 규칙

- 초기 목록과 반복 목록을 이어서 비교해 전체 순서가 같을 때만 처음부터 반복으로 합친다. 유한 반복 횟수와 무한 반복을 구분한다.
- 전환 턴 전의 행동은 반복 묶음으로 줄이고, 전환 턴·전환 후 반복을 따로 표시한다.
- 원본 명령에서 확인한 무조건 자기 사망은 종료로 표시한다. 부활 경로가 있는 적은 일괄 종료시키지 않는다.
- 페이즈 전환의 의도 교체와 다음 목록 위치를 보존한다. 골리아 계열은 전환 직후의 행동을 분리하고, 실제 커서에서 시작하는 반복 목록으로 표시한다.
- 소환 개체의 실제 이름과 이동 링크를 본체에 표시한다. 소환 카드는 기본 접힘 상태이며 링크를 누르면 열고 제목으로 초점을 이동한다.
- 상태의 부여·조회·소모·제거 참조를 원본 ID로 연결한다. 설명이 제공되는 상태 정의의 중복 본문은 제거한다.
- 피해량은 붉은색, 실드는 푸른색으로 강조하고 피해 단위는 pt로 표시한다. 현재 HP 비례 설명의 중복을 제거한다.

## 재사용한 구현

- `js/story-info.js`의 몬스터·전투 카드, 행동 행과 기존 접기 동작.
- `css/pages/dzone-info.css`의 카드·행동 목록·반복 표시 구성요소.
- `js/dzone-richtext.js`의 생성 참조 렌더러와 `js/character-effects.js`의 키보드·포커스 툴팁.
- 원본 분석·생성 로직은 비공개 추출기 저장소에 유지한다. 공개 브라우저에는 행동 종료·전환 정보와 표시용 데이터만 제공한다.

## 무작위 소환 후보와 교차 대상 트리거 보완

- 소환 명령의 `Random(N)` 값과 같은 임시 변수의 배타 분기가 완전한 경우에만 후보 그룹을 만든다. 종류별로 접어 표시하고, 실제 행동 순서의 종류 수와 각 변형의 첫 행동을 표시한다. 후보 수를 소환 수량으로 표시하지 않는다.
- 상태 소유자, 명령 대상, 플레이어를 거쳐 원래 적에게 돌아오는 경로를 추적한다. 단순 스택 조회는 실행 경로로 간주하지 않는다. 참조 대상의 상태 보유를 확인할 수 없으면 동작을 확정하지 않는다.
- 네프레아의 조건부 의도 4개와 추가 행동 1개, 다른 몬스터의 동일 구조 추가 행동 1개를 공통 규칙으로 복원했다. 이름·몬스터 ID 분기는 사용하지 않는다.
- 미해석 후보는 비공개 `triggered-action-audit.json`에 발동 경로와 확정 여부를 기록한다. 이 후보 수는 실제 누락 확정 수가 아니다.
- 공개 테스트 374개, 비공개 관련 테스트 19개 통과. 320/390/719/721/768/1024/1280px, 글자 200%, 후보 그룹 키보드 펼침, 변형 상세, 새 행동 툴팁, 기존 융재금구 표시를 확인했다. 전투 구성·수치 원본 비교 388개 스테이지 차이 0건.

## 행동 순서 변형을 같은 카드에 표시

전체 스토리의 무작위 소환 그룹 94개를 검사했다. 이름·외형·능력치·시작 상태·스킬 효과·조건부 행동 등은 같고 행동 순서만 다른 후보를 공통 비교 함수로 분류하여, 20개 카드로 통합했다. 연옥의 거미·냉주·연옥 거미 떼·냉주 무리에 적용됐다. 원본 후보와 행동 순서는 변경하지 않았다.

통합된 개체는 별도 종류·변형 토글 없이 일반 카드로 표시한다. 능력치·시작 상태는 한 번만 렌더링하고, 행동 목록에 무작위 선택 안내와 패턴별 순서·반복·전환을 모두 제공한다. 다른 능력치나 효과를 가진 후보는 통합하지 않는다.

공개 테스트 376개 통과. 320/390/719/721/768/1024/1280px, 320/1280px 글자 200%, 844×390 가로 화면에서 넘침 없음. 성신편 5장 보스의 소환 카드가 2개이며, 각 카드의 원본 패턴 3개와 공통 능력치 블록 1개, 소환 영역 내 추가 토글 0개인 것을 브라우저로 확인했다.

## 연속 행동과 턴 번호 표시

단일 행동이 연속되는 유한 구간은 반복 박스 대신 `4~5` 같은 범위로 렌더링한다. 둘 이상의 행동을 반복하는 구간은 기존 반복 표현을 유지한다. 턴 전환 구간에 실제 시작·종료 턴을 전달하여 6턴부터 계속되는 행동은 `6~`, 8턴의 단발 행동은 `8`, 9턴부터 계속되는 행동은 `9~`로 표시한다. 특정 몬스터의 예외 없이 모든 행동 구간에 적용한다.

공개 테스트 377개 통과. 320/390/719/720/721/768/1024/1280px와 320/1280px 글자 200%에서 넘침 없음. 브라우저에서 연속 행동 범위, 모든 6턴부터 구간의 `6~` 표시와 반복 박스 제거를 확인했다.

## 같은 소환 종류의 수치 차이와 HP 범위

이전의 통합 조건에서 능력치까지 같아야 한다는 제한을 제거했다. 같은 외형·종류·상태 정의·스킬 효과를 가진 무작위 후보는 수치 차이가 있어도 한 카드로 합친다. 원본 변형별 능력치와 계산된 행동 설명은 각 패턴에서 보존한다. 카드의 공통 HP는 최소~최대 범위로 표시하고, 완전히 같은 HP는 단일 값으로 표시한다. 서로 다른 수치의 상태 효과와 조건부 행동도 각 패턴의 실제 값으로 렌더링한다.

소환 영역 제목은 `소환 개체`로 통일하여 `「군집 효과」 효과로 등장` 같은 소환 경로 문구를 제거했다. 성신편 5장 일반 전투의 냉주 무리·연옥 거미 떼 후보 6개가 카드 2개로 표시되고, 각각 3개 패턴과 `HP 17,485 ~ 20,982`를 표시함을 확인했다.

공개 테스트 377개 통과. 320/390/719/720/721/768/1024/1280px와 글자 200%에서 카드 수, 범위 HP, 패턴별 수치, 토글 제거, 경로 문구 제거, 가로 넘침을 확인했다. 전체 94개 무작위 그룹에 같은 기준을 적용해 128개 통합 카드가 생성된다. 능력치와 설명 원본은 변경하지 않았다.

## 소환 정보 밀도·툴팁 정수·스택 표기

카드의 소환 배지와 중복되는 영역 제목, 전체 후보 수 안내, 패턴별 공격력·방어력·개별 HP 나열을 제거했다. 공통 HP 범위와 짧은 `3가지 패턴 중 무작위로 하나를 사용합니다.` 안내만 남겼다. 안내는 본문 보조 글꼴로 표시하고, 상태 설명과 패턴 제목 사이에 1.25rem 간격을 두었다.

원본 상태의 실행 명령에서 직접 피해를 주는 것을 확인한 툴팁에만 수치 피해의 정수 올림과 pt 표기를 적용한다. 암중 파괴의 `88.2 피해`는 `89pt의 피해`로 표시된다. 비율 수치는 변경하지 않는다. 모든 스토리 표시 데이터와 키워드 툴팁의 `중첩`은 `스택`으로 정규화한다.

공개 테스트 378개, 비공개 관련 테스트 20개 통과. 320/390/719/720/721/768/1024/1280px와 글자 200%에서 중복 안내 제거, 보조 글꼴, 상태-패턴 간격, 가로 넘침을 확인했다. 브라우저 키보드 툴팁에서 89pt 표시와 소수 제거를 확인했다. 388개 스테이지의 중첩 표기 잔존 0건을 회귀 검사한다.

## 조건 설명과 소환 카드 접기

통합 소환 카드도 기존 `details/summary` 카드 렌더러를 사용하도록 복원했다. 종류별 카드 하나는 유지하고 카드 제목으로 전체 내용을 접거나 펼친다. 별도 후보 그룹·변형 토글은 만들지 않는다.

빈 의도 이름과 내부 상태명을 노출하던 문구는 원본의 난수 분기·임시 변수 설정·트리거 시점으로 다시 생성한다. 직전 행동 기록과 난수의 모든 조합에서 연속 중복 방지가 확인된 경우에만 그 의미를 표시한다. 기록을 입증하지 못한 경우 반복 제외를 추측하지 않는다. 실제 무작위 행동은 고정 반복 순서가 아닌 A~D 후보와 설명 한 번으로 표시한다. 다른 임시 변수 조건도 실제 변수를 설정한 의도 이름으로 풀어 쓴다.

공개 테스트 379개, 비공개 관련 테스트 22개 통과. 전체 스토리의 빈 의도·내부 상태명 조건 문구 0건. 320/390/719/720/721/768/1024/1280px 및 글자 200%에서 무작위 안내, 중복 설명 제거, 통합 소환 카드의 키보드 접기·펼치기와 가로 넘침을 확인했다.

## HP 비례 피해 수식의 정수 범위

피해가 첫 번째 인수에 있는 일부 형태만 변환하던 제한을 제거했다. 원본 설명의 모든 `Damage:ArgN` 인수를 확인하고, 알려진 공격력과 잃은 HP 비율로 계산되는 식은 최소·최대 피해를 각각 계산한 뒤 올림하여 정수 범위로 표시한다. 원본 숫자·변수 조건을 보존하며 알 수 없는 현재 HP를 최대 HP로 가정하지 않는다. 해당 스테이지 폭노의 고치는 `713~1,426pt`로 표시한다.

공개 테스트 380개와 비공개 관련 테스트 24개 통과. 320/390/768/1024/1280px 및 글자 200%에서 정수 범위, 빨간 피해 강조, 소수 수식 미노출과 넘침을 확인했다.
추가로 피해 단위가 생략되거나 `만큼 피해`로 번역된 원문도 같은 경로로 처리한다. 388개 스테이지에서 해당 HP 비례 피해 수식 34건을 검사했으며 원래 수식이 남은 사례는 0건이다. 재생성 후 공개 380개·비공개 24개 테스트, 반응형 검사와 Pages 산출물 준비를 다시 통과했다.

## 공통 규칙의 전체 너비 배치

## 플레이어 감시 상태·후속 명령·전환 상태 연결

플레이어의 숨김 상태가 `FrontEnemy.GetStateLayer`로 적의 상태를 감시하고 동일 이름·설명을 복제한 경우, 이를 플레이어가 받는 효과로 표시하지 않는다. 독립적인 플레이어 효과와 지원 선택은 보존한다. 이름·설명 없이 현재 의도 실행 뒤 의도 위치만 한 칸 옮기는 후속 스킬은 별도 공격으로 표시하지 않고 해당 구간의 반응 규칙으로 연결한다.

단계 전환 스킬의 실제 명령에서 다음 반복 목록과 자신에게 무조건 부여하는 상태를 추적하여 기존 공유 전환 상자에 연결한다. 생성 상태 설명의 스택 인수를 해석하며, 스테이지별 정의를 복제하여 다른 스테이지 수치가 섞이지 않도록 한다. 산의 기생충은 탐식 공양과 보물 다섯 종·파괴 조건을 표시한다. 피해 단위 정규화가 강조보다 늦던 순서를 수정하여 `점의 피해`도 빨간 피해 강조를 받는다. 시작 효과는 공통 레이아웃에서 한 열로 배치한다.

공개 테스트 382개·비공개 관련 테스트 28개 통과. 388개 스테이지의 새 전환 상태 문맥 38건에서 미해석 설명 인수와 소수 스택 잔존 0건. 320/390/719/720/721/768/1024/1280px, 가로 844×390px 및 글자 200%에서 플레이어 감시 상태 제외·실제 플레이어 효과 보존·전환 상자·추가 행동·피해 색상·수직 배치·넘침을 확인했다. Pages 산출물 준비 통과. 공개 배포는 수행하지 않았다.

## 부활과 전환 스킬 사이의 임시 상태

부활 감시 명령에서 전환 의도를 지정할 때 같은 대상·조건으로 부여한 상태를, 해당 전환 스킬이 실제로 해제하는 동일 State ID와 연결한다. 이 중간 상태를 보물 등 전환 후 지속 상태와 합치지 않고, 기존 공유 전환 상자에 획득→해제 순서로 표시한다. 산의 기생충은 부활 시 피해 완전 면역 획득→탐식 공양 실행 시 제거를 표시한다. 다른 대상의 제거와 다른 조건의 부여는 연결하지 않는다.

## 정적 참고 화면의 실시간 잔여 횟수와 실드 강조

## 스토리 지도와 전투 위치 연결

기존 `js/dzone-info.js`의 `renderMap`·`activateMap` 구현을 `js/battle-map.js`로 옮겨 단일 렌더러로 사용한다. 융재금구는 기존 어댑터로 호출하고, 스토리는 지도 제목과 한 전투 지도 축약 여부만 전달한다. `css/pages/dzone-info.css`의 실제 타일·아이콘·표면·접기·초점 스타일과 `images/dzone/map` 자산을 공유한다. 타일 치수와 좌표 간격은 기존 비율을 유지한 rem 단위로 바꿔 글자 확대와 함께 확대한다.

비공개 `tools/story/publish-story-maps.mjs`는 동일 원본의 Stage·Map·MapNode·MapNodeType과 스토리 전투 인벤토리를 대조한다. MapType 1은 원래 좌표·행 홀짝을 보존하고 명시된 벽은 제외하며 누락된 기본 바닥을 복원한다. MapType 2는 원래 노드 순서를 한 줄 경로로 표시한다. 같은 칸의 여러 전투와 시작 위치는 보존한다. 결과 `data/story/maps.json`에는 315개 전투 스테이지(망각편 189개 포함)가 있고 연결되지 않은 전투 구성은 0건이다. 원본 추출 테이블은 ignored 작업 폴더에 유지하며, 지도 생성도 기존 스토리 재생성 명령에 연결한다.

385개 공개 테스트·데이터 검증·Pages 산출물 준비 통과. 스토리 8126/7825/146233에서 320/390/719/720/721/768/1024/1280px 및 가로 844×390px, 글자 200%를 검사했다. 각 조건에서 지도 접기·펼치기, 전투 버튼의 Enter 동작, 카드 열기와 초점 이동, 페이지 넘침과 타일 확대를 확인했다. 기존 융재금구도 320/390/768/1024/1280px 및 200%에서 같은 동작을 확인했다. 스토리·융재금구 화면을 시각 확인했다. 로컬 미리보기에만 반영했다.

## 장별 특수 노드와 기본 기믹

망각편 1~9장·성신편 1~6장에서 지도에 등장하는 Type 30 노드를 각각 Event의 선택지 명령과 대조했다. 15개 장에서 14종의 노드를 사용하며, 망각편 9장은 8장의 노드 종류와 이벤트를 재사용한다. 지도 라벨은 확보된 한국어 Skill 이름 또는 검증된 기능명(행동력 감소·각인 부여·각성체 변환)을 사용한다. 공식 한국어 이벤트명으로 추정한 번역을 붙이지 않는다.

비공개 `tools/story/chapter-mechanics.ko.json`에는 원본 선택지·명령·카드·상태를 확인한 기본 효과의 한국어 설명과 원본 참조를 기록한다. `chapter-mechanics.mjs`는 참조 원본의 해시와 이벤트 선택지가 연결하는 명령을 검사하며, 변경되거나 미검토한 새 노드 종류이면 재검토 전 생성을 중단한다. 공명 강화가 있는 효과는 기본 효과와 변경되는 항목을 구분하며, 전체 공명 레벨별 수치를 확정한 목록으로 표시하지 않는다.

스토리는 기존 `renderRuleCard`를 공통 규칙과 장별 기믹 설명이 함께 사용한다. 기존 지도 버튼 렌더러·클릭 동작에 설명 이동 대상 옵션만 추가했다. 특수 노드를 누르면 해당 기믹의 접힘을 열고 설명 카드로 초점을 옮긴다. 전체 15장·320/390/768/1024/1280px의 75개 조합에서 키보드 이동과 글자 200%·넘침을 검증했다. 기존 지도 반응형 및 전투 이동도 회귀 확인했다. 공개 테스트 386개·데이터 검증·Pages 산출물 준비 통과. 로컬 반영.

## 특수 카드 전문과 공명 강화 경로

앞 절의 기본 기믹 요약만으로 선택에 필요한 정보를 제공하지 못한다는 피드백에 따라, 요약 대신 강화 전 카드의 행동력·효과·카드 속성과 전체 공명 트리를 표시한다. 15개 장의 공명 135개 노드, 149개 레벨 효과, 107개 선행 연결을 원본 Resonance 및 StageGroup.BattleBuff와 대조한다. 선행 노드의 OR/AND 조건은 게임의 ResonanceDataUtils.IsAllPreResonanceActive와 CommonDefine.ResonanceUnlockType(0=Or, 1=And)을 확인했다. 강화 경로는 도착 노드까지의 조건식을 유지하여 표시하며, 이름을 누르면 해당 노드 전문으로 이동한다. 망각편 9장은 원본 67082의 설명에 따라 8장의 공명 전부를 계승하고 자체 노드를 추가한다.

기존 `renderRuleCard`·`disclosure`와 `BattleMap.showDetail`을 공유한다. 선행 노드 이동은 중첩된 접힘을 모두 열고 초점을 옮긴다. 레벨 효과는 누적 합계로 임의 합산하지 않고 원본의 각 레벨 전문을 보여준다. 카드 설명에는 조합 재료 5종, 공명으로 해금되는 열매와 직접 연결된 시작 상태도 포함한다. 예를 들어 열매의 왜곡된 소망과 소모 후 재생성은 Skill.ExistState를 통해 연결한다. 숨김 상태를 일반 효과로 노출하지 않는다.

카드명·직접 연결된 상태 설명은 확보된 한국어 텍스트를 사용한다. 공명 노드의 한국어 원문은 확보되지 않았으므로 명칭과 레벨 효과는 검토한 원본 번역임을 화면에 명시한다. 비공개 `chapter-resonance.mjs`, `resonance.ko.json`, `resonance-review.json`, `mechanic-cards.ko.json`, `mechanic-card-sources.json`에서 원본 참조와 검토한 효과를 관리한다. 카드·상태·명령·공명·장 연결의 원본이 변경되거나 노드/레벨이 누락되면 재검토 전 생성을 중단한다. 공개 JSON을 직접 수정하지 않는다.

320/390/719/720/721/768/1024/1280px에서 15개 장의 120개 조합을 검사한다. 200% 글자 확대·선행 노드 Enter 이동·페이지 및 카드 내부 넘침·콘솔 오류를 검사하고, 데스크톱·모바일 화면을 시각 확인한다. 공개 전체 테스트·데이터 검증·Pages 산출물 준비와 지도/전투 표시 회귀 검사를 통과했다. 로컬 미리보기 반영이며 커밋·푸시·배포는 수행하지 않았다.

## 공명 연결도와 선택한 노드의 상세 정보

전체 강화 경로 및 모든 노드의 전문을 동시에 펼치는 표현은 폐기했다. `js/story-resonance.js`는 공통 노드 데이터의 depth와 preIds에서 중복 없는 노드 위치·연결선을 계산한다. 트리에서 노드 이름·최대 레벨을 확인하고 하나를 선택하면, 아래의 상세 정보 한 개를 교체한다. 선택한 노드에 연결된 선과 노드를 강조한다. 사용자 보유·강화 상태는 가정하지 않는다. 실제 인게임의 아이콘·배치를 그대로 복제한 화면이 아니라, 검증된 연결 관계를 배치한 웹용 연결도다.

노드 상세에는 기존 `js/story-info.js`의 `renderRuleCard`·`disclosure`·리치 텍스트·툴팁 렌더러를 사용한다. 별도 상세 카드 구현을 복제하지 않는다. 선행 조건 버튼과 특수 카드의 해금 조건도 같은 노드 선택 동작을 호출한다. 선택할 때마다 기존 상세 DOM을 교체하므로 레벨별 효과가 다른 노드와 섞이거나 전체 설명이 누적되지 않는다.
