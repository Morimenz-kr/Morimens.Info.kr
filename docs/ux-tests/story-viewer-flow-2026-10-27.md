# 스토리 뷰어의 행동 흐름과 효과 표시 검증

`codex/story-viewer-flow`에서 기존 스토리 뷰어를 보완했다. 메인 병합·푸시·배포는 하지 않았다.

## 표시 규칙

- 초기 목록과 반복 목록을 이어서 비교해 전체 순서가 같을 때만 처음부터 반복으로 합친다. 유한 반복 횟수와 무한 반복을 구분한다.
- 전환 턴 전의 행동은 반복 묶음으로 줄이고, 전환 턴·전환 후 반복을 따로 표시한다.
- 원본 명령에서 확인한 무조건 자기 사망은 종료로 표시한다. 부활 경로가 있는 적은 일괄 종료시키지 않는다.
- 페이즈 전환의 의도 교체와 다음 목록 위치를 보존한다. 골리아 계열은 전환 직후의 행동을 분리하고, 실제 커서에서 시작하는 반복 목록으로 표시한다.
- 소환 개체의 실제 이름과 이동 링크를 본체에 표시한다. 소환 카드는 기본 접힘 상태이며 링크를 누르면 열고 제목으로 초점을 이동한다.
- 상태의 부여·조회·소모·제거 참조를 원본 ID로 연결한다. 설명이 제공되는 상태 정의의 중복 본문은 제거한다.
- 피해량은 붉은색, 실드는 푸른색으로 강조하고 피해 단위는 pt로 표시한다. 현재 HP 비례 설명의 중복을 제거한다.

## 재사용한 구현

- `js/story-info.js`의 몬스터·전투 카드, 행동 행과 기존 접기 동작.
- `css/pages/dzone-info.css`의 카드·행동 목록·반복 표시 구성요소.
- `js/dzone-richtext.js`의 생성 참조 렌더러와 `js/character-effects.js`의 키보드·포커스 툴팁.
- 원본 분석·생성 로직은 비공개 추출기 저장소에 유지한다. 공개 브라우저에는 행동 종료·전환 정보와 표시용 데이터만 제공한다.

## 검증 결과

| 항목 | 확인 내용 |
|---|---|
| 순서 보존 | 모든 스토리 데이터의 초기·반복 목록을 압축 전후 세 번 순환하며 대조 |
| 원본 함수 | 초기/반복 경계, 교체·삽입 동작 및 골리아 전환 후 커서 선택을 오프라인 원본 함수와 대조 |
| 자폭 | 작은 꿀벌은 세 행동 후 종료하며 응시·모독을 표시하지 않음 |
| 상태 연결 | 등불 신도·경건한 등불 신도의 피의 서약, 거목의 기도 툴팁 확인 |
| 소환 | 분열체·치어·어군·어왕의 실제 대상 이름, 이동·펼치기·키보드 초점 확인 |
| 수치 보존 | 388개 스테이지의 전투 편성, 본체·소환 개체 HP·공격·방어·레벨·체력바를 검증된 기준 데이터와 대조 |
| 화면 | 320·390·719·721·768·1024·1280px에서 가로 넘침 없음, 모바일·데스크톱 실제 화면 확인 |
| 접근성 | 소환 링크 높이 44px 이상, Enter 이동과 툴팁·Escape, 글자 200%, 844×390 가로 화면 확인 |
| 검사 | 공개 테스트 370개, 관련 비공개 테스트 12개, 데이터 검증·배포 아티팩트 생성 통과 |

원본 함수 검증은 행동 선택·교체·커서에 대한 검증이다. 모든 스킬 효과와 모든 실전 조건의 전체 전투 재현을 의미하지 않는다. 로컬 증거 파일은 `.generated/story/`에 보관하며 배포하지 않는다.
