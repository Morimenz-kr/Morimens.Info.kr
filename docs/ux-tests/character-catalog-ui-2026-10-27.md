# 각성체 정보 목록과 보유현황 공통 UI 검증

## 변경 범위

`codex/character-catalog-ui`는 `842de15` 메인에서 분기했다. 각성체 정보 목록은 보유현황의 계역별 구획, 초상 카드와 버튼형 필터를 사용한다. 정보 목록의 카드는 해당 각성체 공략 페이지로 이동하며, 등급·상시/한정·계역·역할·이름 필터를 함께 적용한다. 상시/한정은 최초 출시 분류를 유지한다.

## 공유 구현

- 원본 카드·계역 렌더러: `js/inventory_checker.js`의 `renderCharacters`, `renderCharacterCard`.
- 원본 필터: `inventory_checker.html`의 `.filter-pills` 버튼과 `js/inventory_checker.js`의 선택 동작.
- 위 구현을 `js/character-catalog-ui.js`로 옮겼다. 보유현황과 정보 목록의 `js/index.js`가 같은 카드·계역·필터 렌더러와 이벤트 연결 함수를 호출한다.
- `css/pages/inventory_checker.css`의 실제 공통 스타일과 600px 반응형 규칙을 `css/character-catalog.css`로 이동했다. 두 페이지가 같은 파일을 불러온다.
- 보유현황의 돌파 컨트롤과 공유 이미지 생성은 기존 구현을 유지한다. 선택 상태와 돌파 컨트롤을 공통 카드의 옵션으로 전달한다.
