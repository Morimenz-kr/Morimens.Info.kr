# 각성체 정보 필터 UI 검증

## 적용 범위

`codex/character-catalog-ui` 브랜치에서 각성체 정보 목록의 필터만 보유현황의 버튼형 UI로 변경했다. 카드 크기·이름·계역 태그·역할 표시, 기존 목록 순서와 공략 링크는 메인 `842de15`의 구현을 유지한다. 앞서 추가했던 계역별 구획과 작은 초상 카드·패널은 제거했다.

## 공유 구현

- `inventory_checker.html`의 필터 버튼과 `js/inventory_checker.js`의 선택 동작을 `js/character-filter-ui.js`로 옮겼다. 두 페이지가 동일한 버튼 렌더러·선택 상태·이벤트 연결 함수를 사용한다.
- `css/pages/inventory_checker.css`의 `.filter-pills`, `.filter-row`, `.filter-pill` 및 600px 반응형 규칙을 `css/character-filters.css`로 이동했다. 카드 스타일은 이동하지 않았다.
- 각성체 정보의 획득 분류 버튼은 전체·상시·한정이며, 등급은 별도 드롭다운에서 전체·SSR·SR을 선택한다. 상시/한정은 최초 출시 분류를 유지한다. 침식·로탄을 한정으로 수정하여 상시는 SSR 24명과 SR 4명, 한정은 SSR 34명이다.
- 계역·역할은 기존 드롭다운을 재사용하고 이름 검색을 함께 적용한다. 보유현황의 통상·망각편·성신편 필터는 기존 값을 유지한다.
- 검색창 아래 필터는 320·390px에서 두 줄, 599·601·768·1024·1280px에서 한 줄로 배치된다.
