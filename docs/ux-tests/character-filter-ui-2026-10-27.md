# 각성체 정보 필터 UI 검증

## 적용 범위

codex/character-catalog-ui 브랜치의 각성체 정보 목록 필터 변경이다. 기존 카드와 목록 순서, 공략 링크는 유지한다.

## 구성과 재사용

- 상시·한정, 챕터는 독립된 드롭다운이다. 챕터는 망각편·성신편이며 침식·로탄은 한정·성신편이다.
- 등급·계역·역할은 상세 필터에 배치했다. 접어도 조건을 유지하고 활성 조건 수를 표시한다.
- 기존 list.html의 네이티브 select와 css/components.css의 공통 site-disclosure를 재사용했다. 공통 접기 화살표·포커스·키보드 동작을 따른다.
- js/summon-classification.js는 data/gachatype.json의 안정 ID를 기준으로 획득 분류와 챕터를 각각 계산한다. 최초 출시 분류를 유지한다.
- 보유현황은 js/character-filter-ui.js와 css/character-filters.css의 기존 공유 필터 구현 및 카드 렌더러를 유지한다. 침식·로탄은 성신편 필터에 포함된다.
- 600px 이하에서는 기본 필터를 두 줄로 배치한다. 상세 필터는 화면 폭에 따라 줄바꿈한다.

| 상세 필터 | 접기·펼치기, 닫은 뒤 조건 유지와 활성 조건 수, Enter 키보드 동작 통과 |
