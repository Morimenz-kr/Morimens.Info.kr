# 왼쪽 공간 활용과 귀속 토글

이 기록의 왼쪽 표 배치는 사용자 요청 범위를 벗어난 변경으로 v11에서 되돌렸다. 현재 능력치 표·입력·결과는 모두 오른쪽이다. 귀속 토글, 미리보기 보존과 저장 관련 수정은 유지한다.

v11 복원에서는 세팅 표를 원래 개요에 남기고, 전사·목표의 능력치 패널을 오른쪽 입력·결과 패널 안에 둔다. 왼쪽 표용 행과 행 확장을 제거했다. 자동 검사에 세 탭의 표가 오른쪽 안에 있는지 명시적으로 추가했으며, 소스·산출물의 기능과 반응형 33조건이 모두 통과했다(`D:/MorimensCodexTemp/v11-right-restore-{source,artifact}.log`). Chrome 복원 화면은 `D:/MorimensCodexTemp/v11-right-restored-user.png`다.

비밀계약의 최대 320px 크기와 좌우 구조를 유지했다. 능력치 8행을 세 탭 모두 이미지 바로 아래로 옮겨 왼쪽의 빈 공간을 사용한다. 세팅 탭에서는 원래 표의 DOM 노드를 옮겨 기존 합계 갱신을 그대로 유지한다. 전사·목표의 오른쪽은 입력과 실제 실행 결과를 표시하고, 실행 전에는 빈 결과 영역을 만들지 않는다. 모바일의 순서는 이미지→조작·결과→능력치다.

전사와 목표에도 기존 세팅 탭과 같은 네이티브 귀속 스위치를 추가했다. `state.contractBound`를 공유하고 변경 즉시 자동 저장한다. 귀속 변경은 능력치와 이미지에 반영되며 옵션 ID·레벨·잠금·미리보기를 변경하지 않는다. 이미 완료한 실행의 횟수·비용·원래 옵션 결과도 보존한다. 진행 중 목표 계산은 귀속을 바꾸면 취소한다.

현재 탭의 장비가 전부 비어 있으면 해당 귀속 토글은 해제·비활성화한다. 목표 장비만 장착된 경우 목표의 귀속을 저장·복원하며, 두 세팅이 모두 비면 귀속 값도 false로 정규화한다. 결과 안내는 오른쪽 동작 영역에 두어 결과가 없거나 아직 실행하지 않아도 오류를 볼 수 있다.

독립 검사에서 기존 세팅 탭의 귀속만 바꾸면 전사 미리보기를 폐기하는 문제를 발견했다. 실제 옵션 변경 여부를 구분하고, 귀속의 시각적 갱신을 부위 선택 이벤트와 분리했다. 세팅에서 Ⅰ 부위를 보고 전사에서는 Ⅵ의 결과를 대기 중일 때도 귀속만 바꾸면 Ⅵ의 미리보기·교체 대상을 보존한다.

## 후속 재검증과 v10 보완

독립 레드팀과 UI 에이전트의 재검증에서 두 가지를 추가 보완했다.

- 목표 프리셋에 귀속이 저장되지 않아 켜고 저장→끄기→불러오기 후에도 꺼진 상태가 남았다. 새 스냅샷에 선택적 불리언 `contractBound`를 추가하고 불러올 때 세 탭과 그림·합계를 동기화한다. 필드가 없는 구형 프리셋이나 불리언이 아닌 잘못된 값은 현재 귀속을 유지한다. 모두 미장착이면 귀속을 해제·비활성화하는 규칙은 유지한다.
- 실제 6부위 결과에서 우측이 길어지면 Grid가 두 행에 남는 높이를 분산해 이미지 아래 간격이 12px에서 66.14px로 늘었다. 데스크톱 행을 `min-content minmax(0,1fr)`로 지정해 첫 행은 이미지의 자연 높이로 유지하고 남는 공간은 두 번째 행에서 처리한다. 이미지 320px와 프레임 435.5px는 바꾸지 않는다.

수정 후 소스 320px·산출물 390px에서 귀속 켜고 저장→끄기→불러오기, 세 탭 체크 상태 일치, 세팅 Ⅰ·전사 Ⅵ 미리보기와 선택/교체 대상 보존, 실제 Ⅵ만 교체되고 Ⅰ 옵션은 그대로인 것, 구형 프리셋의 켜짐·꺼짐 양 상태 유지, 빈 장비 정규화를 독립 검증했다. 실행 중 취소, 수치 12%→18%, 원래 결과값 보존, 저장 실패 시 기존 값과 재시도·재접속도 통과했다. 증거는 `D:/MorimensCodexTemp/redteam-v10-target-preset-binding-proof.json`, `redteam-final-crossed-binding-proof.json`, `redteam-final-bound-active.log`다.

독립 UI는 실제 v10 소스·산출물에서 6부위 결과를 생성해 12px 간격·능력치 8행·단일 384px 결과 스크롤·마지막 카드 접근을 확인했다(`D:/MorimensCodexTemp/ui-v10-final-bound-proof.json`). 자동 회귀도 세 탭의 33조건을 양 서버에서 각각 통과했다. 여기에 목표 프리셋 귀속 복원과 실제 6부위 결과의 12px 간격·마지막 카드 노출 검사를 추가했다(`v10-review-source.log`, `v10-review-artifact.log`). 이번 수정 후 추가 확정 문제와 브라우저 실행 예외는 없었다.
