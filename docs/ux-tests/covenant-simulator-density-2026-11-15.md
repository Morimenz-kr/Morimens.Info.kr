# 비밀계약 시뮬레이터 여백 조정 · v12

## 변경

- 원본 비밀계약 그림 최대 320px, 프레임 352px와 16px 내부 패딩을 유지한다. 200% 글자 확대에서도 그림은 커지지 않는다.
- 데스크톱 왼쪽 열은 그림과 카드 패딩에 맞는 386px로 잡고, 남은 폭을 오른쪽 작업 영역에 할당한다. 세 탭에 같은 기준을 적용한다.
- 양쪽을 감싸며 왼쪽 아래까지 늘어나던 추가 배경/테두리를 제거한다.
- 전사·목표의 오른쪽 영역 안에서 입력과 능력치를 나란히 배치한다. 실행 결과는 계속 오른쪽 입력 아래에 두며, 모바일에서는 기존 입력→결과→능력치 순서를 유지한다.
- 고정 높이로 입력을 자르거나 총합을 접지 않는다. 긴 실행 결과만 기존의 독립 스크롤을 유지한다.
- 목표 레벨 선택 폭을 104px에서 같은 기본 크기의 6.5rem으로 바꿔 200% 글자 확대 시 ‘Lv 4 이상’이 잘리지 않게 한다.

## 검증

`node tools/test-covenant-simulator-layout.mjs`를 소스(8766)와 생성 사이트(4185)에 각각 실행한다.
각각 세 모드 × 11 조건: 320, 390, 768, 1024, 1101/1102/1103, 1280px, 가로 844×390, 320/1280px 글자 200%.

- 가로 넘침, 8개 능력치 행의 잘림, 부위 버튼 터치 크기, 레벨 선택 글자 폭을 측정한다.
- 원본 그림 크기가 세 모드에서 동일하고, 1280px에서 글자 확대 여부와 관계없이 320px인지 확인한다.
- 능력치/결과의 오른쪽 위치, 그림 카드 자연 높이, 큰 바탕 제거를 회귀 조건으로 검사한다.
- 전사·교체, 여섯 부위 목표, 범위 선택, 귀속/미리보기 유지, 탭 전환, 프리셋 저장/복구와 새로고침을 검사한다.
- 여섯 부위 실행 결과와 마지막 카드까지 접근할 수 있는지 확인한다.
- 증거: `.generated/scarecrow/simulator-layout-proof-8766/` 및 `...-4185/`의 스크린샷과 results.json.

1280px 기본 세팅에서 전사/목표 오른쪽 패널 높이는 기존 약 669/680px에서 약 458px로 줄어든다. 결과가 추가되거나 프리셋을 펼치면 내용에 따라 높이가 늘어나며 입력을 고정 높이로 자르지 않는다.
