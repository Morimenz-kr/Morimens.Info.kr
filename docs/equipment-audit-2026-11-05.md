# 장비·비밀계약·유물 검증 결과

기준일: 2026-11-05. 기존 사이트 표기와 안정 ID를 유지하면서 확보한 클라이언트 res15의 Item·Skill·State·Cmd·TrinketSuitEffect·CollectionHall 및 한국어 자료를 대조했다. 수치·제련·발동 조건·지속 시간·횟수 제한·생성 카드와 도감 누락을 확인했다. 최초 검증 당시에는 로컬 수정 상태였다.

## res18 대조와 통합 검증

2026-11-08에 보관된 res18의 `config.ab`·`text_kr.ab`·`share.ab`가 res15와 동일한 SHA-256임을 재확인했다. [번들 대조 및 통합 검사 결과](character-skill-audit-2026-11-05.md#res18-대조와-통합-검증)를 기준으로 설정·한국어 설명을 유지한다. res18에서 추가된 릴리 의상 카드 번들은 이 장비·유물 도감 수정 범위에 포함하지 않는다.

원격 main 통합 후 명륜·은열쇠·비밀계약·유물의 실제 상세창을 각각 320·390·768·1024·1280px에서 기본 글자와 200% 글자로 재검사했다. 40개 조합에서 가로 넘침·대화상자 경계 이탈·이미지 실패·스크립트 오류가 없었으며, 명륜 15강 조작과 Escape 닫기를 확인했다. 자동 테스트는 448개 통과, 데이터 오류는 0개이며 기존 경고 85개가 남는다.

## 수치와 표시 기준

은열쇠 설명의 이전 수치는 서로 다른 연구 단계에서 찍힌 스냅샷이었다. 56개 설명을 공통 기본 금기 학식 81의 계산 결과로 맞췄으며, 이 변경을 56개 모두의 밸런스 오류로 집계하지 않는다. 실제 상세창은 선택한 금기 학식에 따라 수치를 다시 계산한다. 혼돈 공격·방어 보정은 기본값 1을 표시 기준으로 사용한다.

명륜의 제련 0~3과 주옵 강화 0~15는 별개다. 현재 Config의 품질별 증가량과 속성 환산치를 대조한 결과, SSR·SR은 15강에서 기본값의 2배, R은 3배다. 예를 들어 R 「폭식」의 광기 회복은 0~3강 1.2, 4강 1.4, 15강 3.6이며 종전 화면의 15강 2.4는 잘못된 값이었다. 현재 Config 기준 2,352개와 과거 서버 관측의 24종 대표 곡선을 비교했고, 수정한 실제 화면 함수도 2,352개 모두 통과했다. 과거 서버 관측을 이번 작업의 신규 실시간 조회로 집계하지 않았다.
