- [ ] 수집 시각·표본 범위·미공개/미수집 장비·실패/빈 결과를 구분한다.
- [ ] 캐릭터별 세팅·자주 쓰인 조합·구역 담기·중복 제외·편성기 보내기를 운영 데이터로 연결한다.
- [ ] 보유 조건 기반 탐색과 실제 기록이 뒷받침하는 대체 각성체 표시를 구현한다.
- [ ] 통계를 기본 진입으로 전환하고 참고용 수동 자료는 출처와 구분을 유지한다.

완료 조건: 운영 사이트에서 실제 수집 기록의 조합·장비·옵션을 탐색하고 편성기로 가져온다. 사용 빈도를 승률·최적 세팅으로 표현하지 않는다. 상세 운영법·대체별 장비 공략은 후속 범위다.

[마일스톤](https://github.com/Morimenz-kr/Morimens.Info.kr/milestone/5) · [추적 이슈 #256](https://github.com/Morimenz-kr/Morimens.Info.kr/issues/256)

## M6. 환몽 심잠 지도·적 정보 확장

현재 판정: **자료 조사 · 전용 사이트 기능 미착수**

전용 구현 브랜치·완료 증거가 없다. 환몽 관련 원본 설정 후보를 조사한 상태와 서비스 기능 구현을 구분한다. M3의 `js/battle-map.js`, `js/battle-view.js` 및 스테이지 구조는 재사용 기반이며 환몽 지도·진행 규칙의 완성을 뜻하지 않는다. M3 이후 별도 범위를 확정한다.

- [ ] 실제 서비스 모드·스타일·난이도와 내부/과거 설정을 분리한다.
- [ ] 지도·노드 연결, 무작위 묶음·조건 분기, 강화 효과·적 보정을 원본 참조에 연결한다.
- [ ] 대표 경로·누락 참조를 검사하고 미확인 동적 경로를 표시한다.
- [ ] 사이트 탐색·지도·적 정보와 계산기 불러오기를 연결하고 공개 배포를 확인한다.

완료 조건: 지원 범위의 지도·노드 효과·적 구성을 확인하고 계산기로 전달한다. 정적 출현 후보를 실제 확정 경로로 표시하지 않는다.

[마일스톤](https://github.com/Morimenz-kr/Morimens.Info.kr/milestone/6) · [추적 이슈 #257](https://github.com/Morimenz-kr/Morimens.Info.kr/issues/257)

## 진행 순서와 완료 기준

딜미터기 우선 경로는 **M1 → M2 → M4**, **M3 → M4**다. M5는 병행 가능하고 M6는 M3 이후 확장한다. M1의 보류된 공유 기능을 M2의 필수 선행 구현으로 되살리지 않는다.

관련 소스의 main 반영, 제품 배포, 배포에서의 핵심 흐름 검증을 구분한다. UI 변경은 `docs/responsive-design.md`의 반응형·분기점·가로 화면·글자 확대·키보드 기준을 따른다. 데이터 변경은 원천·stable ID 관계·생성 진단·회귀 검사를 기록한다. 기존 검증 기록은 날짜와 범위를 보존하며 이번에 재실행한 것으로 표시하지 않는다. 모든 마일스톤의 기한은 미정이며 이번에는 닫지 않는다.

이전 상세 현황은 [점검 전 main 문서](https://github.com/Morimenz-kr/Morimens.Info.kr/blob/f90d046af26281bef01b6ed785c2417ed37302fe/docs/development-milestones.md)에서 확인할 수 있다. 원본 번들·추출물·인증 정보·개인 식별 기록은 공개하지 않는다.
