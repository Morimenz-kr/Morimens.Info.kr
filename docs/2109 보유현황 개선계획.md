# 2109 보유현황 개선계획

작성일: 2026-11-07

## 목적

메인의 기존 보유 현황 UI를 최대한 유지하면서 성장 관리·프리셋·추천 조합 기능을 추가한다.

현재 `codex/roster-growth-preview`의 프리뷰는 카드 크기·배치·탭·배경까지 변경 범위가 크다. 메인의 기존 화면을 기준으로 외형을 복원하고, 새 기능은 필요한 위치에 추가한다. 프리뷰에서 구현한 저장·백업·성장 처리 로직은 재사용한다.

이 문서는 다음 수정의 계획이며, 아래 UI 변경을 구현 완료했다는 의미는 아니다.

## 1. 기존 화면의 틀 유지

다음 요소는 기존 형태를 유지한다.

- 배경 이미지와 중앙 패널.
- 제목과 우측 보유 수 표시.
- 각성체·명륜 탭 모양.
- 검색창과 통상·망각편·성신편·역할 필터.
- 혼돈·심해·혈육·초차원별 구분.
- 작은 썸네일 카드와 선택 테두리.
- 돌파 조절 버튼, 이미지 복사·미리보기.

현재 프리뷰의 큰 성장 카드를 기본 화면에서 걷어내고, 여러 캐릭터를 한눈에 확인하는 기존 목록 밀도를 복원한다.

## 2. 썸네일 카드의 최소 확장

기본 카드에는 기존 정보 아래 짧은 성장 요약과 편집 진입점을 추가한다.

```text
┌─────────────┐
│             │
│ 기존 썸네일 │
│             │
│   라모나    │
│  < 3돌 >    │  ← 기존 돌파 조절
│ Lv.60       │
│ [성장 정보] │  ← 추가
└─────────────┘
```

- 성장 정보 버튼에는 미입력·일부 입력·입력 완료 상태를 함께 알린다.
- 기본 화면에서 모든 특성·스킬을 펼쳐 카드 크기를 키우지 않는다.
- 미입력 값과 실제 0단계를 구분한다.

목록 상단에는 `성장 정보 펼치기`를 제공한다. 활성화하면 같은 카드 안에 다음 요약을 추가로 표시한다.

```text
영혼 단련       10
광기의 징조     12
내재 영격        5
스킬       전체 최대
```

위 수치는 표시 예시다. 실제 값과 상한은 캐릭터별 원본 성장 자료를 사용한다.

기본은 기존처럼 간결하게 유지하고, 성장 상태를 확인할 때 정보량을 늘린다. 펼쳤을 때도 기존 영역별 묶음과 카드 너비를 우선 유지한다. 좁은 카드에서 읽기 어려워지면 글자를 과도하게 줄이지 않고 배치와 열 수를 조정한다.

## 3. 기존 스타일의 성장 편집 모달

카드의 성장 정보 버튼을 누르면 기존 사이트의 스타일을 사용하는 편집 모달을 연다.

- 레벨·돌파.
- 영혼 단련·광기의 징조·내재 영격.
- 실제 스킬 이름별 레벨.
- 성장 프리셋 적용.
- 저장·저장 후 다음 캐릭터.

카드 클릭은 기존대로 보유 선택에 사용한다. 성장 편집 버튼과 돌파 화살표는 보유 선택을 발생시키지 않도록 분리한다. 기존 돌파 화살표 조작을 유지한다.

모바일에서는 같은 내용을 읽고 조작할 수 있는 모달 또는 바텀시트로 제공한다. 닫은 후에는 기존 목록 위치와 편집 버튼의 포커스를 복구한다.

## 4. 기존 조작부에 새 도구 배치

상단에 버튼을 계속 늘리지 않고 기존 위치와 역할을 기준으로 배치한다.

| 기존 위치 | 수정 방향 |
|---|---|
| 각성체·명륜 탭 | 같은 모양으로 추천 조합 탭 추가 |
| 모두 선택·모두 해제 | 유지하되 현재 검색 결과에 적용된다는 범위 표시 |
| 목록 조작부 | 일괄 편집 추가 |
| 보조 도구 메뉴 | 프리셋 관리·파일 내보내기·불러오기 배치 |
| 이미지 복사·미리보기 | 기존 기능과 위치 우선 유지 |

일괄 편집을 시작했을 때만 편집 대상 체크와 적용 도구를 표시한다. 보유 여부와 편집 대상 선택은 별도 상태로 관리한다.

일괄 적용에서는 다음 동작을 제공한다.

- 현재 검색 결과 또는 보유 캐릭터 전체를 편집 대상으로 선택.
- 돌파 등 기존 값을 유지하면서 지정한 성장 항목만 변경.
- 미입력 항목만 채우기 또는 지정 항목 덮어쓰기.
- 캐릭터·스킬별 상한에 맞춘 최대값 적용.
- 적용 전 변경 수와 제외 항목 확인.
- 적용 후 직전 작업 되돌리기.

성장 프리셋은 여러 캐릭터에 적용할 설정 묶음이며, 계정 백업은 전체 보유·성장 정보를 저장하는 파일이다. 두 기능을 구분해서 안내한다.

## 5. 같은 패널 안의 추천 조합

추천 조합을 별도의 시각 디자인으로 만들지 않고 기존 탭 안의 콘텐츠로 구성한다.

- 상단에는 기존 필터 버튼 스타일로 파·보유 조건·포함·제외 조건을 제공한다.
- 결과에는 4인 썸네일과 부족한 항목을 우선 표시한다.
- 성장 비교와 장비 상세는 조합을 펼쳤을 때 제공한다.
- 캐릭터 보유 여부와 성장·장비 비교 결과를 구분한다.
- 실전 기록의 성장값을 필수 최소 스펙으로 단정하지 않는다.
- 프리뷰의 합성 데모는 실제 기록·채용 통계와 구분해 표시한다.

보유만 등록한 사용자도 조합을 탐색할 수 있도록 한다. 미입력 성장값 때문에 조합 전체를 숨기지 않는다.

## 6. 수정 순서

1. **기존 외형 복원**: 메인의 배경·패널·탭·필터·영역별 썸네일 배치를 기준으로 복원한다.
2. **성장 진입점 추가**: 카드에 레벨·성장 정보 버튼을 추가하고 선택적으로 성장 요약을 펼친다.
3. **편집·프리셋 연결**: 개별·일괄 편집과 프리셋·백업 기능을 기존 스타일에 연결한다.
4. **추천 탭 연결**: 기존 탭·필터·썸네일 스타일로 조합 검색과 비교 기능을 배치한다.

전체 초기화나 기존 브랜치 변경 폐기 없이 필요한 화면 파일과 스타일을 단계적으로 수정한다. 기존 보유 데이터는 보존하고, 프리뷰 전용 저장 방식은 유지한다.

## 7. 검증과 완료 기준

- 기존 화면과 수정 화면을 같은 너비에서 나란히 비교한다.
- 기존 목록 밀도, 영역별 구분, 보유 선택, 돌파 조작이 유지되는지 확인한다.
- 성장 편집과 보유 선택이 서로 간섭하지 않는지 확인한다.
- 기존 이미지 복사·미리보기가 동작하는지 확인한다.
- 320·390·768·1024·1280px 및 변경한 전환 너비의 앞뒤 1px을 확인한다.
- 가로 화면과 글자 200% 확대에서 가로 넘침·잘림·겹침을 확인한다.
- 모달·일괄 작업 도구·제보 버튼이 주요 조작부를 가리지 않도록 확인한다.
- 키보드와 터치 조작, 포커스 표시·복귀를 확인한다.
- 성장 저장·프리셋·파일 복원·되돌리기와 기존 데이터 보존을 검증한다.

최종 방향은 **기존 보유 현황 화면을 익숙하게 유지하면서, 필요할 때 성장 정보를 확인하고 편집할 수 있도록 확장하는 것**이다.
