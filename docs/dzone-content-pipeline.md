# 융재금구 패치 데이터로 설명 갱신하기

## 필요한 입력

같은 리소스 버전에서 추출한 `Config.MonsterConfig`, `Skill`, `State`, `Cmd`, 대응 한국어 Text 테이블, 인라인 키워드 설정이 필요하다. 추출 원본은 비공개 디렉터리에 유지한다.

몬스터 TID는 스킬·상태를 찾는 키다. **TID만으로 난이도별 HP·공격력을 확정할 수는 없다.** 전투 구성과 순서는 StageGroup → Stage → Map/MapNode → BattleConfig, 능력치는 StageDifficulty/StageMonsterData 및 몬스터 배율까지 필요하다. 이 입력으로 만든 시즌 기본 스냅샷을 아래 생성기에 전달한다. `MonsterPoint`를 좌우 좌표처럼 숫자순 정렬하지 않는다.

## 원본으로 갱신

1. 새 시즌의 전투 구성·난이도·기본 능력치 스냅샷을 준비한다. 게임 실행이나 각 전투 클리어는 이 생성 명령의 요구사항이 아니다. 암호화된 패치 파일의 추출 과정은 별도다.
2. 스킬·상태·조건부 행동을 갱신하면서 참조를 함께 생성한다.

```powershell
node tools/build-dzone-site-data.mjs --base <시즌-기본.json> --static <추출-테이블-폴더> --keywords <inline-keyword-icons.json> --out .generated/dzone-candidate.json
```

3. 이미 검증된 HP·배치를 유지하고 설명 연결만 다시 만들 때는 다음 명령을 사용한다.

```powershell
node tools/dzone-content.mjs --base data/dzone_current.json --static <추출-테이블-폴더> --keywords <inline-keyword-icons.json> --out .generated/dzone-candidate.json --strict
```

4. `contentAudit.diagnostics`가 비었는지 확인한다. 누락된 참조·미해결 수식·알 수 없는 태그·모호한 이름 연결은 출력 생성을 막는다. `warnings`는 별도 검토한다. 원본이 불완전한 항목을 임의의 값으로 채우지 않는다.
5. 기존 시즌은 HP·전투 순서·난이도·다중 체력·소환체 수치 회귀 검사를 수행한다. 신규 시즌은 해당 시즌의 Stage/스탯 테이블과 비교한다. 기존 시즌의 테스트 통과가 새로운 스케일링 공식의 정확성까지 보증하지는 않는다.
6. 검증된 후보만 배포 데이터에 반영하고 `npm test`, 화면·툴팁·반응형 검증 후 미리보기로 배포한다. 원본 폴더를 배포 폴더에 복사하지 않는다.

## 연결과 출력의 규칙

- 원문의 인라인 태그를 보존한다. 같은 한국어 단어가 있다는 이유만으로 전역 툴팁을 붙이지 않는다.
- Skill/State → Cmd → 실제 부여되는 State·생성되는 Skill을 따라간다. 같은 이름의 일반판·강화판, 플레이어용·몬스터용은 동일한 상태로 취급하지 않는다.
- 실제 명령 참조가 없는 단어에는 유사한 설명이나 아이콘을 추측해서 붙이지 않는다. 본문 아이콘은 인라인 설정에서 명시한 이미지에 한정한다.
- `richDescription`/`keywordGlossary`는 생성물이다. 직접 편집하지 않는다. 교정은 실제 State/Skill ID와 원본 조건을 기준으로 생성기에 반영하고 회귀 테스트를 추가한다.
- 툴팁에는 해당 효과와 그 효과의 발동 조건·지속·횟수만 적는다. 다른 규칙과의 관계나 작업 과정 해설은 넣지 않는다.
- 조건부 공격을 따로 표시하더라도 원래 보유 상태와 초기 스택은 숨기지 않는다. 상태에는 전체 효과를, 조건부 행동에는 연결된 상태·발동 조건·공격 수치를 표시한다.
- 시작 상태는 MonsterConfig의 보유 상태에 더해, 무조건적인 자기 대상 `BSTStateOnAdd`/`BSTBattleBegin` 명령으로 부여되는 상태까지 추적한다. 공격 중 부여·사망 후 부여·조건부 부여를 초기 상태로 간주하지 않는다.
- 정적 기본값과 전투 중 현재 HP·스택 수에 따른 값은 구별한다. 현재 HP를 최대 HP로 간주한 고정 숫자를 표시하지 않는다.
- 알려지지 않은 신규 효과나 명령 형식은 검증·구현이 필요하다. 이 도구가 임의의 미래 패치를 무검증으로 처리한다고 간주하지 않는다.

## 현재 원본 확인 사항

| 항목 | 실제 연결 / 처리 |
|---|---|
| 눈막에 감춰진 자취 | State 149227: 방어막 유지, 광기 폭발 피해 증가·명령 카드 피해 감소 |
| 서리 방패 전환 | State 149229 → Cmd 149212 → State 149773 |
| 서리 방패 | State 149773: 능동 피해 시 손패 1장에 임시 둔화, 턴당 최대 5회, 방어막 파괴 시 제거 |
| 몬스터 죽음 저항 | State 94600: 치명적 피해 시 스택 소비·HP 회복. 플레이어 확률형과 분리 |
| 자멸 | Skill 73477: 텍스트와 Cmd 73511은 Arg2를 참조하지만 Para에 없음. 횟수는 생략하고 원본 결함 경고 유지 |

‘서리 방패는 일반 방어막뿐’이라는 이전 설명은 잘못된 연결이었다. 한국어 이름만 비교하면 이 오류가 재발하므로, 위 명령 연결을 테스트로 고정한다.
