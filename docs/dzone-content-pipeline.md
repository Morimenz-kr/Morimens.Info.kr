# 융재금구 데이터 갱신하기

생성 도구와 원본 참조·계산식의 세부 유지보수 문서는 개인 도구 묶음에서 관리한다. 먼저 [비공개 데이터 도구 사용하기](private-data-tools.md)에 따라 도구와 원본 자료를 준비한다.

1. 개인 도구 묶음의 동일 이름 문서를 읽고 실제 Skill/State/Cmd 참조를 기준으로 데이터를 재생성한다. 생성 JSON을 직접 보정하거나 한국어 이름만으로 효과를 연결하지 않는다.
2. 생성 진단과 경고를 검토하고, 검증된 전투 구성·능력치를 보존한다. 해당 시즌의 원본과 비교하고 비공개 도구의 회귀 검사를 실행한다.
3. 공개 저장소의 테스트·데이터 검사·배포 아티팩트 생성을 실행한다. 화면이나 툴팁을 변경했다면 화면 및 반응형 검증도 수행한다.
4. 검증된 결과만 반영한다. 원본과 도구를 공개 커밋이나 배포 폴더에 포함하지 않는다.
