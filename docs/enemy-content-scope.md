# 전투 콘텐츠별 적 정보 범위

전체 적 정보는 콘텐츠와 난이도, 스테이지에 연결된 전투 구성으로 제공한다. 같은 몬스터라도 등장 장소에 따라 능력치와 초기 상태, 행동 조건이 달라지므로 몬스터 종류와 스테이지별 전투 정보를 구분한다. 화면 구성 방향은 [스테이지별 전투 구성 화면](stage-encounter-design.md)에 정리한다.

## 집계 기준

2026년 10월 6일에 로컬 res154/build51 추출본을 정적 분석한 결과다. 최신 클라이언트를 다시 추출한 결과나 실제 출시 콘텐츠의 총수로 해석하지 않는다.

- 설정 전체: 스테이지 그룹 1,062개, 스테이지 6,525개, 전투 편성 6,805개, 몬스터 설정 623개.
- 이번 연결 범위: `Stage.BelongGroup → StageGroup`, 격자 지도와 순차 노드 목록의 전투 노드 유형 1·2·3, 해당 `BattleConfig`의 직접 배치 몬스터.
- 연결된 고유 전투 편성: 5,262개. 직접 배치된 고유 몬스터: 469종. 테스트 콘텐츠도 포함한다.
- 위 경로에서 스테이지 그룹·지도·숫자 노드 참조·전투 편성·몬스터 참조 누락은 각각 0건이다. 이벤트 내부 전투, 무작위 노드 묶음, 소환 경로의 검증 결과는 아니다.
- 지도 셀에 나열된 숫자 노드 참조를 수집했다. 셀 내 문자열 인자와 조건의 의미, 실제 이동 가능성은 판정하지 않았다. 연결 결과는 출현 후보 목록이다.

## 난이도와 하위 콘텐츠

스토리의 장·스테이지별 상세 정리는 [스토리별 스테이지와 전투 구성](story-encounter-scope.md)을 따른다.

스토리의 실제 집계 대상은 망각편 1~9장과 성신편 1~6장의 노말·하드다. 광란·성신편 7장·프롤로그를 제외한 388개 스테이지 중 315개에 직접 전투가 연결되며, 고유 전투 구성은 1,173개, 직접 배치 적은 367종이다. 위 표의 원본 전체 집계와 구별한다.

| 콘텐츠 | 설정에서 구분되는 범위 | 표시 전에 필요한 판정 |
|---|---|---|
| 메인 스토리 | 망각편 1~9장, 성신편 1~6장, 노말·하드 | 스테이지별 전투 조건과 능력치; 광란과 성신편 7장 제외 |
| 특파 기록과 의식 잠수 | 일반, 어려움, 광란 | 캐릭터, 외전, 개방 단계 |
| 이벤트 | 개별 이벤트의 스테이지 그룹, 이몽세계, 다차원 연결, 캠퍼스 고양이 도전 | 이벤트별 실제 난이도 및 특수 규칙; 모든 이벤트를 일반·하드로 일괄 처리하지 않음 |
| 성장 재료 | 재료별 던전과 단계 | 사용되는 능력치 행, 난이도 단계 |
| 장신구 | 던전별 단계 | 보상 던전과 전투 편성 연결 |
| 주간 보스 | 보스별 스테이지 | 전투 분기와 단계 전환 |
| 무광의 영역 | 상위 층 설정, 계역별 구간, 순환 구간 | 상위 층 그룹 2개는 직접 소속 스테이지가 없음; 실제 입장 경로 확인 |
| 환몽 심잠 | 스타일과 난이도, 탑 모드 관련 설정 | 실제 서비스 모드 구분, 무작위 출현 및 진행도별 능력치 |
| 융재금구 | 시즌, 금지구역, 경보 단계 | 현행과 과거 시즌의 개방 여부, 공통 상태와 경보 보정 |
| 월드 보스와 레이드 | 원초를 향한 공투, 변칙적인 조류, 원초와의 재전, 고양이의 은화 사냥 | 이벤트 기간, 단계 및 특수 규칙 |
| 체험과 훈련 | 이벤트 체험, 상시 체험, 별자리 편 체험, 전투 훈련 | 튜토리얼 또는 고정 파티 조건 |
| 질주하는 환희 특급 열차 | 구형과 신형 설정, 각 난이도 | `MapType 3`의 노드 묶음과 선택 규칙 |
| 모의 전투 | 독립 스테이지 그룹 | 실제 사용·개방 여부 |
| 내부 테스트 | 테스트 스테이지와 환경 | 공개 목록에서 제외; 출시 콘텐츠와 공유하는 전투를 함께 삭제하지 않음 |

## 적 정보의 데이터 단위

| 단위 | 보존할 정보 |
|---|---|
| 몬스터 종류 | ID, 한국어 이름, 초상, 분류, 종족·계역, 스킬과 상태의 원본 참조 |
| 스테이지 | 콘텐츠, 그룹, 난이도, 입장 조건, 능력치 기준, 공통 초기 상태 |
| 전투 편성 | 전투 ID, 유형, 노드, 편성 내 개체 순서와 배치 위치 |
| 배치 개체 | 몬스터 ID, 같은 적의 등장 수, 전투별 능력치와 행동 조건 |
| 소환과 전환 | 소환 주체, 발동 조건, 등장 대상, 수치 보정, 부활과 단계 전환 |

같은 적이 한 전투에 두 번 배치되면 두 개체를 보존한다. 도감의 적 종류 수를 줄이기 위한 중복 제거가 편성의 개체 수를 바꾸면 안 된다. 같은 전투 편성이 여러 노드에 재사용되면 각 노드에서 같은 전투 정보로 연결한다.

## 아직 범위에 포함되지 않은 경로

이번 집계는 직접 배치 적의 출현 후보 범위다. 전체 출시 적과 융재 수준의 상세 전투 정보를 제공하려면 다음 경로를 별도로 대조해야 한다.

- 이벤트 노드의 선택지와 효과에서 시작하는 전투, 숨겨진 전투.
- `MapNodeGroup`과 탑 모드 등의 무작위 편성·선택 규칙.
- 배치 적의 Skill·State·Cmd에서 이어지는 소환·부활·몬스터 교체.
- `StageDifficulty`와 `StageMonsterData`의 실제 선택, 초기 상태 및 콘텐츠별 수치 보정.
- 현재 클라이언트에 남은 과거 이벤트와 시즌의 실제 개최·개방 이력.
- 최신 추출본과의 차이, 한국어 텍스트와 초상 누락, 미출시·개발용 변형.

기존 몬스터 조사에는 전투 편성 전체의 직접 배치 참조가 지목하는 497종과 소환 명령이 지목하는 153종이 있다. 이는 이번 스테이지 연결 범위와 다른 집계이며 서로 겹친다. 두 숫자를 더해 전체 등장 적 수로 사용하지 않는다.

## 조사 산출물

비공개 조사 도구와 원본은 공개 저장소에 추가하지 않는다. 로컬 도구 `private-tools/scarecrow/audit-stage-encounters.mjs`는 콘텐츠별 집계, 스테이지별 전투·몬스터 연결 및 미해석 경로를 `.generated/scarecrow/battle-survey/stage-encounter-scope.json`에 저장한다. 공개에는 검증된 표시 데이터와 필요한 설명만 포함한다.
