# res22 사이트 반영

인게임 V2.6.2.5, `Z1G_2026_11_OB / res22 / build11`을 res18 원본과 비교해 확인한 변경을 반영했다. 원본 번들과 생성 도구는 비공개 추출기에 보관한다.

- `Skill:146647`의 실드 첫 인자에서 중복된 열쇠 지령 강도 계수를 제거하고, `silverkey_list`의 수식·원문·연구 의존성을 함께 갱신했다. 원초의 기억 145990·145995는 공개 은열쇠 목록에 없는 내부 선택지여서 장착형 은열쇠로 추가하지 않았다.
- `Skill:4055 → Cmd:1832 → State:134100`을 확인해 셀레스트 강화 부활의 재부여 조건과 중복 방지를 설명했다. `Skill:4138 → Cmd:2336 → State:2595`의 적용 대상은 라모나 자신으로 명시했다.
- `RelicConfig:13780`의 한국어 전투 설명에 남은 중국어 카드명을 현재 한국어 원문으로 갱신했다.
- 현재 73기 융재금구를 현재 Skill/State/Cmd와 WordsEffectConfig 참조로 재생성했다. 단계·배치·능력치를 보존하고, 이번에 변경된 하멜른 적은 현재 기수에 없으므로 임의로 삽입하지 않았다.
- 적 라모나의 미각인 카드 선택 수정, 옛날 잔재 면역 처리와 11월 16일 예약 이벤트는 이번에 확인한 클라이언트 변경이다. 공개 사이트에 대응하는 독립 전투 엔진·이벤트 화면이 없으므로 재현하지 않은 전투나 미래 이벤트를 현재 활성 기능으로 표시하지 않았다.

현재 73기의 1~5파 및 소환체 전체에서 능력치 273행·스킬 수치 3,080개를 대조해 불일치 0건이다. 생성 진단, 표시 검사, 미연결 원본 참조는 0건이다.

74기와 유물 세트 효과는 사용자의 공개 보류 지시에 따라 로컬 후보에만 보관한다. Pages 아티팩트는 현재 공개 기수보다 높은 기수의 전투 데이터·지도·카탈로그 메타데이터를 제외한다. 생성 전에는 로컬 미리보기도 검증하여 기존 원본 검수 규칙은 유지한다.
