# 허수아비 통합 구성

## 기준 소스

두 저장소에서 `codex/scarecrow-checkpoint`를 사용한다. 공개 화면의 구현은 한 곳에만 둔다.

| 구성 | 보관 위치 | 처리 |
| --- | --- | --- |
| 파티 카드·성장·카드 피해 계산 | 공개 `js/scarecrow/` | 무시된 로컬 화면을 정식 소스로 편입 |
| 각성체·명륜·은열쇠 선택 | 공개 `js/party_builder.js` | 실제 원본 렌더러 재사용 |
| 유물 선택 | 공개 `js/relic-info.js`, `relic_info.html` | 선택 콜백을 공유 API로 추가 |
| 비밀계약 선택 | 공개 `js/covenant-picker.js` | 시뮬레이터와 같은 렌더러 사용 |
| 공개 실행 자료 | 공개 `scarecrow/runtime/` | 해시 목록으로 고정 |
| Lua 계산 소스·원본 대조·복원 자료 | 비공개 `simulator/` | portable-workspace 최신 이력과 로컬 계산 작업 통합 |
| 옛 별도 app·character-picker·wheel-picker·workspace-ui | 비공개 이전 커밋 이력 | 활성 파일 삭제 |
| story-battle | 기존 별도 브랜치 | 이번 융재는? 확장 작업으로 유지 |

공개 브랜치는 main의 `722bd8f`에서 시작했다. 비공개 소스는 portable-workspace의 `c9a4580`을 기반으로 로컬 계산기 변경을 병합했다. growth-passives 브랜치는 새 화면의 원본이 아니므로 통째로 병합하지 않는다. 원래 작업 폴더와 미확인 변경은 삭제하지 않는다.

## 버전과 검증 범위

실행 기준은 **res160/build51**이다. 집컴에서 검증한 portable-workspace의 `aef7db8` 자료와 소스를 통합했다. 집컴 원본 실행 2,230건은 정상 2,165건·원본 사용 제한 65건으로 분류됐으며 비정상 거절·엔진 오류는 없었다. 집컴의 브라우저 전체 결과 대조는 37건 부분 검사다.

통합 엔진은 별도 회귀 검사, 성장 경계값 488건, 명륜 두 개 장착, 계산 어댑터 8건을 확인한다. 계산 어댑터와 성장 전체 스냅샷은 res160 원본 바이트코드를 오프라인 Lua 5.4와 WASM에서 실행해 대조한 결과이며 새 네이티브 캡처가 아니다. 과거 res154 보고서는 이력으로 유지한다.

현재 카탈로그의 항목은 안정 ID로 표시한다. 고정 실행 자료에 없는 항목은 `계산 준비 중`으로 표시하며 숨기거나 다른 장비로 대체하지 않는다. 정확한 목록은 빌드 결과의 `build-info.json`에 기록한다.

원본 대조 자료는 기존에 보존한 결과이며 이번 작업에서 게임을 실행해 새로 수집한 결과가 아니다. 전투 종료 후 이월과 모든 조건 조합의 완전한 검증을 뜻하지 않는다.

기본 빌드는 비공개 경로를 요구하지 않는다. 비공개 빌드는 `SCARECROW_ENGINE_PACK`으로 같은 버전의 계산 패키지를 지정하며 버전이 다르면 중단한다. 추출 원본·계정 응답·게임 접근 도구는 공개 빌드에 포함하지 않는다.
