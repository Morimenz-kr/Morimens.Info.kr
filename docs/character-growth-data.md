# 캐릭터 성장 데이터

사이트에 등록된 각성체 61명의 기본 성장 스탯과 레벨업·승급·레벨 상한 확장 재화다. 기준은 클라이언트 리소스 154 / 빌드 51이다. 캐릭터 목록에서 진입하는 `links.html?category=character&id=…`의 캐릭터 정보 → **능력치/육성** 탭에 연결되어 있다.

## 파일

| 파일 | 내용 |
|---|---|
| `data/character_growth.json` | 캐릭터 ID별 1~90레벨 기본 스탯 5,490행, 승급 5단계, 상한 확장 10단계, 잠재력의 레벨 상한 증가 노드 |
| `data/growth_resources.json` | 재화 99종의 한국어 이름·원본 아이콘, 경험치 비약, 원본 등급별 경험치 곡선, 레벨업 비용 규칙 |
| `js/character-growth-data.js` | 레벨별 스탯 조회 및 레벨업·승급·상한 확장 구간의 재화 합산 |

두 데이터 파일의 `source.tables`에는 원본 테이블의 SHA-256을 기록한다. 생성기는 비공개 추출기 저장소의 `tools/growth/build-character-growth.mjs`에 있다. 생성 JSON을 직접 수정하지 않는다.

## 스탯 기준

`characters[사이트 ID].levels`는 레벨 순서대로 `level`, `physique`, `attack`, `defense`를 제공한다. 각 캐릭터의 원본 기본치와 해당 레벨의 성장식을 사용하고, 게임과 같이 올림한다.

- `physique`는 기존 캐릭터 화면에서 **체력**으로 표시하는 능력치다. 전투 중의 실제 HP 수치와 구분한다.
- `statBasis`에 명시한 대로 `talent_attr_lv=0`인 기본 성장 값이다. 장비, 재능, 잠재력 및 승급의 추가 스탯을 포함하지 않는다.
- 레벨에 직접 비례하지 않는 계약 숙련·은열쇠 충전·크리티컬 확률·크리티컬 피해의 원본 설정은 `configuredNonLevelAttributes`에 보존한다. 최종 전투 스탯으로 표시하지 않는다.
- 승급으로 얻는 추가 스탯은 `ascensions[].attributeBonuses`에 별도로 있다. 해당 단계에 새로 얻는 증가량이며, 총 증가량은 도달한 단계까지 합산한다.
- 최대 90레벨은 승급 완료 후 상한 확장과 해당 잠재력 노드를 모두 해금한 경우다. `baseMaxLevel`은 승급 완료 기준 60이며, 캐릭터를 획득하자마자 90레벨까지 올릴 수 있다는 의미가 아니다.

`grade`는 기존 사이트 분류, `sourceQuality`는 원본 등급이다. 변형 캐릭터의 경험치 곡선은 사이트 분류를 재사용하지 않고 원본의 `Quality`로 결정한다. 원본 Purple은 `SREXP`, Orange는 `SSREXP`, 나머지는 `EXP`다.

## 레벨업 비용

| 재화 | 1개당 경험치 |
|---|---:|
| 영지 비약Ⅰ | 500 |
| 영지 비약Ⅱ | 2,000 |
| 영지 비약Ⅲ | 10,000 |

경험치 곡선의 행은 `fromLevel → toLevel`에 필요한 경험치다. 90레벨 다음 행은 제공하지 않는다.

구간 비용은 현재 레벨부터 목표 레벨 직전까지 경험치를 합산한 뒤 **500 단위로 올림**한다. 장미 금권 기본 비용은 올림된 경험치의 0.2배를 내림한 값이다. 계정의 비용 감소 효과와 현재 레벨에 이미 쌓인 경험치는 계산에 포함하지 않는다.

예를 들어 판디아 1→4레벨에는 경험치 900이 필요하다. 비약Ⅰ 2개에 해당하는 경험치 1,000과 장미 금권 200이 기본 견적이다. 1→2, 2→3, 3→4를 각각 올림해 합산하면 금권 300이 되므로, 한 번에 올릴 구간의 비용을 레벨별 금권의 합으로 계산하면 안 된다. 비약Ⅰ 환산 개수는 다른 비약 조합과 비교할 수 있는 값이며, 특정 비약만 사용해야 한다는 뜻이 아니다.

## 승급과 상한 확장

`ascensions`는 `fromRank → toRank`, 전후 레벨 상한, 필요한 재화, 새로 얻는 스탯을 제공한다. 비용은 원본의 **출발 단계 행**에서 읽는다. 판디아 0→1단계는 순백의 조각 9개와 장미 금권 1,800이며, 상한이 10에서 20으로 오른다.

`limitIncreases`는 각 확장 단계에 필요한 재화와 누적 상한 증가량이다. `potencySteps`는 `FrontPotency` 참조로 연결한 실제 해금 순서, 노드 ID, 상한 증가량과 캐릭터 전용 재료 비용이다. 비용은 `AwakerSpecialItem`과 `AwakerPotencyUpgradeConsumeNum`에서 읽는다. 판디아의 +5 상한은 11단계, +10 상한은 15단계이며, 미해금 상태에서 90레벨까지의 견적은 선행 단계 15개를 모두 포함한다.

목표 레벨은 현재 해금 상태 때문에 제한하지 않는다. `quoteGrowthPlan`은 상한 확장을 우선하고, 그것만으로 부족하면 필요한 최소 잠재력 단계와 선행 비용까지 포함한다. 이미 완료한 단계의 재료는 제외한다. 실제 UI의 전체 필요 재화는 이 계획과 레벨업 비용·스킬 강화 비용을 함께 합산한다. 승급 과제의 달성 여부는 판정하지 않는다.

`skillUpgrades`는 기본 6개 스킬 슬롯별 1→6레벨 강화 비용이다. 각 행은 현재 레벨에서 다음 레벨로 강화하는 비용이며 `AwakerSkillUpgrade.SkillLevel`과 실제 `Skill.Slot`으로 연결한다. 광기 폭발의 원본 비용과 강화 배수를 보존한다. 파생·변형 카드는 독립적으로 중복 계산하지 않는다. 스킬별 현재·목표 레벨을 설정하거나 ‘전체 목표 Lv.6’으로 일괄 선택할 수 있다.

## 계산 모듈 계약

브라우저 전역은 `CharacterGrowthData`, Node에서는 CommonJS로 불러온다. 두 JSON을 읽어 다음 함수에 전달한다.

| 함수 | 반환 |
|---|---|
| `statsAtLevel(growth, id, level)` | 해당 레벨의 기본 체력·공격·방어 |
| `quoteLevelUp(growth, resources, id, fromLevel, toLevel)` | 필요 경험치, 과금 기준 경험치, 금권 수량, 비약Ⅰ 환산 수량 |
| `quoteAscension(growth, id, fromRank, toRank)` | 지정 승급 구간의 재화별 합계 |
| `quoteLimitIncrease(growth, id, fromStep, toStep)` | 지정 상한 확장 구간의 재화별 합계 |
| `quoteGrowthPlan(growth, id, toLevel, {rank, limit, potency})` | 목표 레벨에 필요한 승급·상한 확장·선행 잠재력 계획과 재화 |
| `quoteSkillUpgrades(growth, id, selections)` | `{slot, fromLevel, toLevel}` 배열로 선택한 스킬 강화 비용 합계 |

상한 확장의 출발 단계 0은 미확장 상태다. 같은 단계 또는 같은 레벨의 견적은 0이며, 잘못된 범위·역방향 구간·알 수 없는 캐릭터는 오류를 반환한다. 계산 모듈은 해금 조건을 판정하지 않는다.

능력치/육성 탭은 현재·목표 레벨의 기본 스탯과 증가량, 전체 필요 재화의 합계만 제공한다. 재화는 원본 `Item.BaseSortID`로 정렬하여 같은 계열 안에서 상위→하위 순서로 표시한다. 현재 레벨에 필요한 최소 승급·상한·잠재력 단계를 완료한 것으로 계산하며, 수동 해금 설정은 제공하지 않는다. 스킬별 현재·목표 단계는 항상 펼쳐 표시한다. 비약 조합은 남는 경험치를 최소화한 예시이며 보유 재화 조합을 최적화하지 않는다. 별도의 성장 재화 시뮬레이터는 아직 연결하지 않았다.

## 검증 범위

61명의 모든 레벨·승급·상한 확장 재화 참조를 검사했다. 원본 성장 테이블의 90개 행은 정적 추출 테이블과 모든 필드가 일치했다. 기존 사이트에 수록된 체력·공격·방어 성장 값 27개와 새 기본 스탯은 모두 일치했다. 레벨 배열의 실제 `Level` 키, 구간 비용 올림, 변형 캐릭터 경험치 분기, 승급 출발 행 비용, 최대 레벨 경계를 회귀 검사한다.

61명 × 6개 스킬 × 5단계 강화 비용과 재화 99종의 아이콘 참조도 검사한다. 계정별 실제 성장 결과, 재능·장비·잠재력을 합산한 최종 스탯, 보유 비약에 따른 사용 조합과 잔여 경험치는 이번 검증 범위에 포함하지 않는다.


## 특성 재료와 육성 입력

`talentUpgrades`는 `AwakerTalent`의 `AwakerID`와 `TalentType`으로 연결한다. 타입 1은 광기의 징조(12단계), 타입 2는 영혼 단련(10단계)이다. 이름은 한국어 원본에서 가져온다. 현재 단계 0은 미강화이며, 각 단계의 `RequireItem`은 해당 단계에 도달하는 비용이다. 클라이언트 `AwakerTalentExtModel.GetRequireItemByIndex`도 현재 단계 + 1의 비용을 읽는다. 선택 구간의 다음 단계부터 목표 단계까지 합산한다.

화면은 경험치, 스킬, 광기의 징조, 영혼 단련 입력을 구분하고 전체 필요 재화를 마지막에 표시한다. 스킬과 특성의 현재·목표 단계는 슬라이더로 선택한다. 기본 능력치는 레벨에 따른 값이다. 스킬의 `Slot_Awake`와 `Slot_Super`는 영지각성과 광기 폭발로 표시한다. 총 재화에는 레벨 상승에 필요한 승급·상한 확장·잠재력과 선택한 스킬·특성 비용이 포함된다. 61개 각성체의 특성 비용과 재화 101종의 실제 아이콘을 포함한다.


내재영격은 `TalentType` 3의 5단계를 사용한다. 첫 단계가 `DefaultActivation: TRUE`인 대상은 이미 활성화되어 입력과 비용 합산에서 제외한다. 현재 61개 각성체 중 28개에 입력을 표시한다. 단계별 재료는 9719번 아이템 20·40·60·80·100개이며, 0→5단계 합계는 300개다. 재화 레지스트리는 102종이며 원본 아이콘을 사용한다.

승급·잠재력 현재/목표 단계는 레벨에 필요한 최소 단계를 자동 적용하고 직접 높일 수 있다. 레벨 상한을 만족하지 못하는 단계는 자동 보정한다. 성장 능력치는 기본 occupation_master, keeper_energy_eff_2, crit, crit_damage에 AwakerBreakThrough.Attr와 AwakerPotency의 Attr_Promote 보너스를 누적한다. 은열쇠 충전 등급은 실제 에너지 획득량과 구분한다. 레벨별 체력·공격·방어 표는 기본 성장식 값이다. 현재보다 목표 단계가 낮으면 목표를 현재 이상으로 맞추며 이미 완료한 단계의 재료는 제외한다.
