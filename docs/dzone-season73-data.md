## 피해·방어막·회복량의 숫자 표시

원본 한국어 설명에 공격 횟수만 있고 피해량 인자가 빠진 경우, 실제 BEActiveDamage 명령의 인자를 찾아 설명에 복원한다. 5파 보스의 징벌의 번개·각성 후 징벌의 번개·혼돈의 깃발 신호가 이 경우에 해당한다. 최고 위험등급의 기본 피해는 각각 1회당 1,002pt·1,002pt·2,004pt다. 각성 직후 징벌의 번개는 추가 상태 1스택을 반영해 4회로 표시한다. 이후 전투 중 힘·피해 증폭·방어 등의 변화는 기본 피해와 구별한다.

소환 시 명시되지 않은 능력치는 게임의 SpawnMonsterWithConfig와 동일하게 소환체 자신의 StageMonsterData·MonsterConfig 기본값을 적용하고, 명령이 전달한 속성만 덮어쓴다. 소환체 공격을 공격력 비율로 남기지 않는다. 등장 시 최대 HP 비례 방어막도 계산된 정수로 표시한다.

각성 후 부여 효과는 공통 템플릿 대신 선택 난이도와 해당 단계의 HP로 계산한 설명을 사용한다. 부활 시 회복하는 HP도 숫자로 표시한다. 현재 HP에 따라 변하는 회복은 임의의 현재 HP를 가정하지 않고, 계산된 최대 회복량과 비율을 함께 제공한다.

숫자 표시 수정 후 공개 테스트 473개와 비공개 생성기 테스트 99개가 통과했다. 운영 5파 뷰어는 320·390·768·1024·1280px × 7개 난이도, 총 35개 조합에서 세 공격의 실제 피해 숫자를 확인했다. 기존 전투 편성과 본체 능력치 273행은 수정 전과 동일하다.

## 초기 유물의 최대 HP 비례 수치

2026-11-16 점검에서 의식용 단검+의 원본 수식은 데이터에 보존돼 있으나, 뷰어가 전투 중 최대 HP를 계산하지 못해 ‘확인되지 않은 수치pt’로 표시하는 오류를 수정했다. 생성 JSON과 몬스터 능력치는 변경하지 않았다.

- 유물 70731 → 상태 70646 → 명령 70993으로 연결된다. 적의 능동 공격을 받은 뒤 해당 공격자를 대상으로 발동한다.
- 기본 피해는 `ceil(파티 최대 HP × 0.5 × 영식 연구 보정배율)`이다. 명령은 여기에 `(반격 상태 3905 + 임시 반격 상태 3023) × 2`를 더한다. ‘반격 보너스 200%’를 전체 피해의 2배로 해석하지 않는다.
- 적에게 부여하는 상태 70996은 턴 종료 시 제거된다. 해당 적에게 이 상태가 없을 때만 발동하므로 적마다 턴당 최대 1회다.
- 뷰어에는 파티 최대 HP 입력이 없으므로, 선택한 금기 학식의 보정배율을 적용한 최대 HP 비율을 표시한다. 1등급은 최대 HP의 56.5%, 81등급은 183%다. 비율 자체를 정수로 올림하지 않으며, 실제 기본 피해를 계산할 때 최종 HP 곱에 올림을 적용한다.
- 검증한 전체 식과 일치하는 최대 HP 비례식만 처리한다. 알 수 없는 추가 항을 무시해 일부만 계산하지 않는다.
