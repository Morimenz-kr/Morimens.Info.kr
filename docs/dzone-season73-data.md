## 피해·방어막·회복량의 숫자 표시

원본 한국어 설명에 공격 횟수만 있고 피해량 인자가 빠진 경우, 실제 BEActiveDamage 명령의 인자를 찾아 설명에 복원한다. 5파 보스의 징벌의 번개·각성 후 징벌의 번개·혼돈의 깃발 신호가 이 경우에 해당한다. 최고 위험등급의 기본 피해는 각각 1회당 1,002pt·1,002pt·2,004pt다. 각성 직후 징벌의 번개는 추가 상태 1스택을 반영해 4회로 표시한다. 이후 전투 중 힘·피해 증폭·방어 등의 변화는 기본 피해와 구별한다.

소환 시 명시되지 않은 능력치는 게임의 SpawnMonsterWithConfig와 동일하게 소환체 자신의 StageMonsterData·MonsterConfig 기본값을 적용하고, 명령이 전달한 속성만 덮어쓴다. 소환체 공격을 공격력 비율로 남기지 않는다. 등장 시 최대 HP 비례 방어막도 계산된 정수로 표시한다.

각성 후 부여 효과는 공통 템플릿 대신 선택 난이도와 해당 단계의 HP로 계산한 설명을 사용한다. 부활 시 회복하는 HP도 숫자로 표시한다. 현재 HP에 따라 변하는 회복은 임의의 현재 HP를 가정하지 않고, 계산된 최대 회복량과 비율을 함께 제공한다.
