# 융재금구 73기 뷰어 데이터

2026-11-08에 보관된 클라이언트 res154 정적 원본에서 73기 전투·지도·설명을 생성했다. 기존 뷰어의 시즌 선택에 `73기 (미리보기)`를 추가했으며, 기본 시즌과 현재 데이터는 72기를 유지한다.

## 산출물과 범위

| 항목 | 파일 또는 수량 |
|---|---|
| 전투·몬스터·설명·키워드 | `data/dzone_season73.json` |
| 지도 | `data/dzone_maps_season73.json` |
| 원본 | res154의 Config 및 한국어 Text, WordsEffectConfig/키워드 설정 |
| 파동·난이도 | 5파 × 7급, 총 35개 스테이지 |
| 스테이지 그룹 | 1파 83424, 2파 83426, 3파 83425, 4파 83428, 5파 83427 |
| 전투 | 20개 |
| 몬스터 | 고유 TID 38개, 소환체 고유 TID 5개 포함 |
| 초기 유물 | 고유 ID 6개 |
| 추가 이미지 | 초상화 5개 |

이 데이터는 해당 보관 버전의 미리보기다. 최신 res18 설정과 일치하는지, 실제 73기 서버 운영에 변경이 없는지는 확인하지 않았다. 새 클라이언트 원본을 확보하면 동일 생성 절차로 재검증해야 한다. 게임 원본·계정 자료·생성 도구는 공개 산출물에 포함하지 않는다.

## 생성과 원본 대조

비공개 `morimens-data-extractor`의 기본 구성 생성기, 전투 설명 생성기, 지도 생성기를 사용했다. 생성 JSON을 수동 보정하지 않았다. 생성 도구의 실행 파일 해시는 `contentAudit.generator.files`에 기록했다.

- Skill/State/Cmd의 실제 참조와 단계 컨텍스트로 설명·툴팁을 생성했다. 확정 참조의 대상 누락과 외부 테이블 누락은 각각 0건이다.
- 생성 진단은 0건이다. 경고 1건은 `State 3255`의 원본 설명이 비어 있다는 것으로, 해당 표기를 임의의 툴팁으로 채우지 않았다.
- 모든 파동을 원본과 비교했다. 전투 20개, 파동별 몬스터 정의 38개, 소환체 정의 5개, 능력치 266행, 스킬 수치 2,583개에서 불일치 0건이다. 최초·반복 행동의 순서와 중복, 초기 상태·스택, 배치 ID도 비교 범위에 포함한다.
- 3파의 「심판」의 사도는 `State 44807 → Cmd 45183`의 상태 제거·횟수 증가·조건부 재부여·부활·전체 회복을 따라 체력바 3개로 생성했다. 첫 부활의 스킬 44676, 둘째 부활의 스킬 44674를 각각 연결했다. 최대 HP를 변경하지 않는 부활도 합계 HP에 반영하며, 무조건적인 새 체력바로 간주하지 않는다.
- 각성 상태에 전달된 인자, 현재 HP·방어막에 따라 달라지는 피해, 전투 시작 시 저장한 공격력 참조를 처리하도록 비공개 생성기를 보완하고 회귀 검사했다. 분석 캐시 버전도 갱신했다.

- 공개 저장소 테스트 472개 통과, 데이터 검사와 repository 기준 Pages 아티팩트 생성 통과.
- 이미지와 키워드 참조 경로 누락 0건.
- 320·390·768·1024·1280px에서 1~5파 × 7급을 각각 검사한 175개 조합에서 가로 넘침과 JavaScript 오류 0건.
- 몬스터·지도 상세를 펼친 상태, 72↔73기 전환, 320·1280px에서 글자 200% 확대와 키보드 툴팁을 확인했다. 모바일·데스크톱 화면을 렌더링해 시각 검사했다. 레이아웃 분기점은 변경하지 않았다.

로컬 검증 기록은 `.generated/dzone73/`에 보관한다. 정적 원본 대조와 브라우저 검증이며, 실제 전투 재현이나 서버 검증을 뜻하지 않는다. 커밋·푸시·원격 배포는 수행하지 않았다.

## 명칭과 정수 표시 수정

`인지 착란`과 `융식 채묵`은 State 140657 및 대응 표시용 State 140655를 가리키므로 `인지 착란(융식 채묵)`으로 통일했다. State 140653/140656의 `인지 부조화(채묵)`와는 분리한다. 두 상태는 Cmd 140618의 비용 변동과 Cmd 140616의 사용·버림 후 제거를 공유하지만, 전자는 `ErosionColorInk: 1`로 카드 글자를 가리는 효과가 추가된다.

피해·상태 수치의 의미를 생성하는 경로에서 계산 결과를 올림한 정수로 표시한다. 원본 계산식과 전투 배치·HP·공격력·방어력·체력바는 보존했다. 계산할 수 없는 시작 시 공격력 비율은 정확한 분수로 표시하며, 뷰어의 최대 HP `1.5배` 표기는 동등한 `150%`로 변경했다. 동일 상태의 별칭 중복과 정수 처리 회귀 검사를 추가해 관련 비공개 검사 55개가 통과했다.

## 원본 참조 기반 아이콘 전수 검사

숙녀의 Skill 60932 → Cmd 60923 → State 2900은 실제 힘 부여 명령이 있지만, 기존 생성기의 두 글자 이상 필터 때문에 링크가 빠져 있었다. 해당 필터를 수정하고 `State 2900 → MergeStateDisplay 97743 → PowerColourKeywords → 같은 표시 대상의 PowerIconKeywords`로 인라인 아이콘을 결정한다. 상태창 아이콘이나 같은 한국어 이름의 다른 상태를 대신 사용하지 않는다.

원본 명령을 별도로 순회하는 `audit-dzone-presentation.mjs`를 생성기에 연결했다. 이전 데이터에서 한 글자 용어 누락과 임시 힘·봉인·취약 아이콘 문제를 난이도·각성 단계 반복을 포함해 119건 검출했고, 재생성 후에는 0건이다. 최종 산출물의 설명 1,869개, 인라인 참조 1,473개, 원본으로 검증할 수 있는 아이콘 사용 714회를 검사한다. 기대 아이콘은 `contentAudit.presentationAudit.expectedKeywordIcons`에 기록하며, 생성 최종 단계에서 다시 검사한다.

공개 배포 검사도 현재 시즌뿐 아니라 모든 시즌 파일에 적용한다. 73기 미리보기의 아이콘이 누락된 경우 배포를 실패시키는 회귀 검사를 추가했다. 비공개 도구 전체 테스트 90개와 관련 회귀 검사 61개가 통과했다. 원본 능력치 266행·스킬 수치 2,583개 대조에서도 불일치는 0건이다.

## 패턴·툴팁 재대조와 원본 색상 보존

44개 파동별 몬스터·소환체 정의의 패턴 91개를 다시 대조했다. 실행 가능한 Skill/State/Cmd 경로에서 추가 행동·행동 목록 전환·소환·부활 125건을 추적했다. 별도 행동으로 표시된 44건, 소환체로 연결된 27건, 부활 단계로 표시된 4건, 상위 상태 툴팁에 사망 저항으로 설명된 5건, 해당 파동에서 대상이 없거나 조건이 비활성인 45건으로 분류되었으며 미분류 동작은 0건이다. 조건에서 조회만 하는 상태는 실제 부여된 상태로 취급하지 않는다.

원본 서식 태그가 생성 과정에서 제거되는 문제를 수정했다. WordsEffectConfig의 `Damage → redword`, `Block → blueword`, `Energy/EnergyColour → yellowword`, `Heal → greenword`를 따라 피해는 빨강, 실드는 파랑, 광기는 노랑, 회복은 초록으로 보존한다. 원본에 색상 태그가 있는 부분에 적용하며 한국어 단어만으로 색상을 추정하지 않는다. 이 보관본의 73기 본문·툴팁에는 Energy 태그가 없어 노란색 처리는 별도 원본 형식 회귀 사례로 검증했다.

본문 서식 1,017곳과 툴팁 106개의 원본 색상 태그를 독립적으로 검사했다. 58개 툴팁에는 색상 본문을 함께 생성하며, 일반 텍스트 설명과 의미가 동일한지도 검사했다. 최종 생성 진단·표시 검사 오류·전체 파동 원본 대조 불일치는 모두 0건이다. 원본 자체가 비어 있는 State 3255 경고 1건은 유지했다.

최종 공개 테스트 474개, 비공개 도구 테스트 92개, 관련 회귀 검사 68개가 통과했다. 데이터 검사 및 repository 기준 Pages 산출물 생성도 통과했다. 320·390·768·1024·1280px의 175개 파동·난이도 화면에서 아이콘 사용 8,960회와 색상 표시 6,965회를 브라우저로 확인했으며, 가로 넘침·소수점 노출·JavaScript 오류는 0건이었다. 글자 200% 확대와 키보드 툴팁도 확인했다. 검증 범위는 위의 res154 보관 원본이며 최신 서버 데이터 검증을 뜻하지 않는다.

5파 감각의 진화의 `State 80784 → Cmd 81074 → BESummonMonster 79944`는 상태 설명만 있었고 소환 상세가 누락되어 있었다. 상태의 HP 변화 트리거를 따라 소환 규칙과 최초 변이체(원문 초변자)의 능력치·패턴을 생성하도록 수정했다. HP는 본체 최대 HP의 10%, 공격력·방어력은 각각 20%이며, HP 50% 미만·전투당 1회 조건은 원본 상태 설명과 소환 규칙에 유지한다. 조건부 상태 소환과 캐시 재생성 중복 방지 회귀 검사도 추가했다. 추가 소환체 반영 후 원본 대조는 몬스터 정의 38개·소환체 정의 6개, 능력치 266행, 스킬 수치 2,625개 모두 불일치 0건이다.
