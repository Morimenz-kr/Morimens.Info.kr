# 은열쇠 효과 태그 점검 기록

점검일: 2026-11-11. 대상: 획득형 은열쇠 56개.

## 분류 기준

- 수치와 설명은 변경하지 않고 태그만 수정했다. effectFormula를 우선 확인하고, 선택지·파생 카드가 축약된 경우 기존 description과 키워드 사전을 함께 대조했다. 실제 게임 실행 및 최신 클라이언트 재추출 검증은 포함하지 않는다.
- 조건부 효과도 포함한다. 조건 충족 여부를 판정하는 필터가 아니다.
- 직접 효과와 기존 설명에 명시된 파생 카드 효과를 포함한다. 단순 조건에 등장하는 상태(포식·배아 등)는 추가하지 않는다.
- 힘의 획득·감소·탈취, 중독의 부여·발동은 태그에서 유지하고 기본 필터에서 묶는다. 임시 여부는 상세 효과 설명에서 확인한다.
- 카드 회수는 덱·버린 카드 더미의 기존 카드를 손으로 가져오는 효과이며, 카드 추가는 복사본·파생 카드를 생성하는 효과다. 드로우, 카드 비용 감소, 산출력 획득을 구분한다.
- 희생 획득과 즉시 HP 감소, 피해 증폭과 최종 피해 증가, 은열쇠 에너지 회복과 충전 효율·최대치·소모량은 각각 구분한다.
- 봄의 현시의 선택지 태그는 기존 분류를 유지했다. 별들의 가호와 주점의 문의 선택지·파생 카드 태그는 기존 상세 설명을 근거로 보완했다.

## 주요 수정 근거

- 포효하는 피와 모래: 현재 수식 설명에 광기 획득·배아 융합이 있어 보완했다.
- 마지막 서약: 조건부 죽음 저항을 보완했다.
- 부패의 연회: 반격 획득·발동을, 호숫가의 회상: 조건부 중독 발동을 보완했다.
- 잔혹한 인사: 카드 추가를 제거하고 잔해로 수정했다.
- 안개 경계에서 온: 카드 추가를 드로우로 수정하고 조건부 카드 비용 감소를 보완했다.
- 회귀의 문을 넘어·소원을 다시 만나다: 기존 카드를 손으로 가져오는 효과를 카드 회수로 구분했다.
- 신세계를 위하여: 인지 착란·우종을 보완했다. 익사한 순수의 추격에서 소용돌이 장전 획득을 임의로 추론하지 않았다.
- 특별 치료: 적용 횟수 증가도 해당 효과 관련 태그로 유지한다.
- 기적의 강림: 용광로 회복량 적립을 즉시 HP 회복으로 분류하지 않는다.
