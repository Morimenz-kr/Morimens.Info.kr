# ScareCrow 카드 설명과 콘텐츠 지원 대조

점검일: 2026-11-14. 대상 브랜치: `codex/shared-covenant-editor`.

## 수정 결과

기존 빌드의 설명 연결 경고 84건을 해결하고 비비안 스킬 9개를 추가해, 93개 Skill ID를 원본 한국어 설명에 직접 연결했다. `data/scarecrow_card_descriptions.json`에 Skill ID·원본 소유자·슬롯·Cmd ID·텍스트 키를 보존한다. 원본에 소유자 필드가 없는 공용 스킬은 이름으로 소유자를 추정하지 않는다. 이름 비교나 특성의 동명 항목으로 설명을 대체하지 않는다.

기존 `생성 카드 NNN` 임시 이름 23개도 원본 이름으로 변경했다. 순백의 꿈, 기묘한 요리, 신앙의 갈림길, 슈퍼 대집합!, 호화로운 축복 등의 실제 게임 이름을 사용한다.

## 설명의 수치와 상태

`js/scarecrow/card-description.mjs`는 원본 명령의 `GetSkillArgs`와 현재 조건에 선택된 `BattleDesc`/`Desc`/초한 설명 키를 사용한다. 계산 준비 시점의 공격·체질·힘·상태·돌파·카드 레벨을 반영한 원본 표시 인자를 한국어 문장에 대입한다. 설명을 읽기 위해 카드를 실행하지 않는다. 파생 카드도 동일 경로를 사용한다.

인자가 아직 없으면 수치를 임의로 0으로 채우지 않고 준비 상태를 표시한다. 계산 실패 시 오류를 표시하며, 카드·조건 변경 뒤 오래된 비동기 설명이 다른 카드에 들어가지 않도록 막는다. 같은 입력은 캐시하지만 입력이 달라지면 다시 계산한다.

## 종전 미지원 6개

새 명륜의 성장 곡선은 원본 Item의 Quality·WeaponMainAttribute·WeaponSubAttribute가 모두 동일한 기존 검증 곡선과 대조해 연결했다. 제련 단계와 주옵 강화 단계를 구분하며 0·3·15강을 실행 검사했다.

빌드의 `unsupported.characters`, `unsupported.wheels`, `unsupported.keys`는 모두 빈 배열이다. 비비안 편성에서 원초혼돈이 활성화되면 원본 규칙이 일반 지령 사용을 대체한다. 이를 지령 구현 누락으로 처리하거나 원본 제한을 해제하지 않는다.

## 원천과 검증 범위

- 6개 콘텐츠의 원본 설정은 기존에 무결성 검증한 res160 엔진 패키지 안에 있었다. 엔진 패키지를 변경하지 않고 누락된 정제 카탈로그·ID 매핑을 보완했다. 변경된 카탈로그·이미지·매핑 파일의 해시를 런타임 매니페스트에 갱신했다.
- 한국어 텍스트는 공식 res18 번들에서 추출했으며 설치된 게임의 텍스트 번들과 SHA-256이 같음을 확인했다. 패키지 해시와 한국어 원천 번들 해시는 설명 데이터의 `source`에 기록한다.
- 보관된 공식 1.0.22 설정과도 대조했다. 93개 스킬의 소유자·이름·설명·전투 설명·Cmd·Para·OriginalCoefficient, 5개 Item의 상태·인자·옵션·SpParam, 비비안의 스킬 목록·품질·계역에서 비교 필드 차이는 0건이다. 최신 전투 모듈 전체를 새로 교체·검증했다는 뜻은 아니다.
- `npm test` 399개 통과. 기존 계약·지령·계역·상태·연속 적용 회귀 23개와 신규 지원 검사 4개를 검증했다. 신규 검사는 93개 설명의 원본 인자 대입, 6개 콘텐츠 연결·실행, 비비안 Lv.90/돌파 0·3·15/스킬 1·6, 누락 인자·단계·Lua 인자 테이블·소수 처리에 한정한다.
- 데이터 검사와 Pages 산출물 생성, ScareCrow 빌드를 통과했다.
- 브라우저에서 비비안 편성·전용 명륜·은열쇠·원본 설명을 확인했다. 320·390·519·520·521·767·768·769·1024·1280px, 가로 844×390과 글자 200%에서 페이지·계산 화면의 가로 넘침 및 JavaScript 오류가 없었다. 모바일·데스크톱 스크린샷을 확인했다.
- 실제 게임 전투 화면의 피해 수치 대조, 모든 장비 교차 조합, 최신 전투 런타임 전체 호환성, main 통합·공개 배포는 이번 완료 범위가 아니다.

원본 번들·Spine·추출 도구·네이티브 캡처 산출물은 비공개 경로에 유지한다. 공개 브랜치에는 정제 설명·카탈로그·ID 매핑·렌더링한 SD 이미지와 어댑터·검사만 포함한다.
