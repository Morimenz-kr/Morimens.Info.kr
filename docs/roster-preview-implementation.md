# 보유 현황 프리뷰 구현·검증

- 브랜치: `codex/roster-growth-preview` (main `1f9b947`에서 시작)
- 진입: `inventory_checker.html`
- 로컬 프리뷰: `http://127.0.0.1:8794/inventory_checker.html`
- 최신 방향: [2109 보유현황 개선계획](2109%20보유현황%20개선계획.md)에 따라 기존 UI를 유지하는 방식으로 수정.

## 기존 화면을 유지한 변경

- 배경 이미지, 중앙 패널, 제목/보유 수, 기존 형태의 탭, 필터 버튼, 영역별 묶음과 작은 썸네일을 복원했다.
- 1280px에서 메인과 수정본 모두 영역별 썸네일 9열을 확인했다.
- 썸네일 클릭으로 보유를 선택하고, 돌파 화살표를 별도로 조작한다. 라모나·회귀 라모나의 보유 캐릭터 간 돌파 연동을 유지한다.
- 카드 기본 정보는 썸네일·이름·돌파·레벨·성장 정보 버튼이다. 성장 버튼에서 미입력/일부 입력/입력 완료 상태를 표시한다.
- `성장 정보 펼치기`를 켜면 같은 카드 안에 특성 3종과 스킬 요약이 나타난다. 기본 목록에서는 접는다.
- 통상/망각편/성신편·역할·명륜 등급 필터와 별칭/초성 검색을 제공한다.
- 선택/해제는 현재 검색 결과에만 적용하고 버튼 이름으로 범위를 알린다.
- 일괄 편집은 보유 선택과 별도 모드로 동작한다. 프리셋·백업·데모 체험·추가 필터는 추가 도구에 묶었다.
- 기존 이미지 복사·미리보기 진입점을 복원했다. 현재 필터의 보유 각성체 또는 명륜을 이미지로 생성하고 PNG 클립보드 복사·다운로드를 제공한다. 이미지 내부 레이아웃은 프리뷰용으로 새로 생성한다.

## 성장 관리와 데이터

- 캐릭터별 레벨·돌파·특성·실제 이름의 슬롯별 스킬 편집, 다음 캐릭터 연속 편집.
- 개별/일괄 편집에서 프리셋 적용, 사용자 프리셋 생성·이름 변경·복제·삭제.
- 원본 자료의 캐릭터별 상한을 사용하는 최대값, 미입력만/덮어쓰기, 변경·제외 수 미리보기.
- 기존 v2 보유값 읽기, 프리뷰 전용 저장, JSON 백업·병합·교체·복구, 직전 작업 되돌리기.
- 기존 `morimens_inventory_checker_v2`는 수정하지 않고 `morimens_roster_preview_v1`에 저장한다.

## 추천 프리뷰와 한계

- 기존 패널 안의 추천 탭에서 합성 조합 4개, 보유·지원·포함·제외·파 필터, 개인 성장 비교, 데모 조합 내 등장 통계를 제공한다.
- 실제 기록/클리어율/유저 채용률이 아니다. 실전 조회 중계는 활성화하지 않았다.
- ScareCrow 자동 가져오기는 연결하지 않았다. 내 성장 빌드 다운로드는 별도 프리뷰 JSON 형식이며 장비는 포함하지 않는다.
- 비비안은 기존 성장 자료가 없어 보유·돌파만 편집한다. 다른 캐릭터의 상한을 복사하지 않는다.
- 성장 해금 단계·장비·조건부 전투 스탯 검증은 포함하지 않는다.
- 온라인 배포는 하지 않았다.
