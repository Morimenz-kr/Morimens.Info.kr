# 보유 현황 프리뷰 구현·검증

- 브랜치: `codex/roster-growth-preview` (main `1f9b947`에서 시작)
- 진입: `inventory_checker.html`
- 로컬 프리뷰: `http://127.0.0.1:8794/inventory_checker.html`

## 구현

- 카드/상세 목록 보기, 보유/미보유·영역·역할·이름·성장 미입력 필터와 정렬.
- 캐릭터별 레벨·돌파·특성·실제 이름의 슬롯별 스킬 편집, 다음 캐릭터 연속 편집.
- 편집 대상 다중 선택, 보유 전체/검색 결과 선택, 보유 일괄 변경.
- 원본 자료의 캐릭터별 상한을 사용하는 최대값 적용, 미입력만/덮어쓰기, 변경·제외 수 미리보기.
- 사용자 성장 프리셋 생성·적용·이름 변경·복제·삭제.
- 기존 v2 보유값 읽기, 프리뷰 전용 저장, JSON 백업·병합·교체·복구, 보유 이미지 PNG 다운로드, 직전 작업 되돌리기.
- 합성 조합 4개, 보유·지원·포함·제외·파 필터, 개인 성장 비교, 합성 조합 내 등장 통계.
- 시뮬레이터 연결 검토용 프리뷰 빌드 JSON 다운로드.

## 프리뷰의 경계

- 실전 조회 중계·ScareCrow 자동 가져오기는 연결하지 않았다. 빌드 JSON은 별도 프리뷰 형식이다.
- 추천과 등장 통계는 합성 예시다. 실제 기록/클리어율/유저 채용률로 표시하지 않는다.
- 비비안은 기존 성장 자료에 없어 보유·돌파만 편집한다. 자료 없는 값을 다른 캐릭터에서 복사하지 않는다.
- 성장 상한은 원본 자료를 사용하지만 해금 단계·장비·조건부 전투 스탯 검증까지 포함하지 않는다.
- 기존 `morimens_inventory_checker_v2`를 수정하지 않는다. 프리뷰는 `morimens_roster_preview_v1`을 사용한다.
- 기존 이미지 클립보드 복사는 프리뷰에서 PNG 다운로드로 제공한다.
- 온라인 배포는 하지 않았다.

## 검증

- `npm test`: 420개 통과, 실패 0. 이 중 새 보유 데이터 모델 테스트 10개.
- 실제 브라우저: 개별 성장 저장, 최대 스킬, 일괄 프리셋과 빈칸 채우기, 프리셋 저장, 목록 전환.
- 실제 JSON 다운로드 → 같은 파일 불러오기 → 내용 미리보기 → 적용 → 되돌리기 확인.
- 추천 데모: 초기 4개 → 보유만 2개 → 지원 허용 3개 → 골리아 포함 1개 → 골리아도 제외 0개.
- 반응형: 카드·상세 목록·추천 화면 각각 320/390/768/1024/1280px, 경계 379/380·767/768/769·1099/1100/1101px 확인. 페이지 가로 넘침 없음.
- 844×390 가로 화면 확인. 390/1280px에서 루트 글자 크기를 200%로 확대하여 콘텐츠·조작부 확인. 편집 Dialog 200% 확대 가로 넘침 없음.
- 편집 Dialog: 필수 다섯 너비에서 내부 가로 넘침 없음. 닫을 때 성장 편집 버튼으로 포커스 복귀 확인.
- 390px 카드/편집/추천, 1280px 카드/목록/추천 스크린샷 시각 확인.
