## 기존 화면을 유지한 변경

- 1280px에서 메인과 수정본 모두 영역별 썸네일 9열을 확인했다.
- 썸네일 클릭으로 보유를 선택하고, 돌파 화살표를 별도로 조작한다. 라모나·회귀 라모나의 보유 캐릭터 간 돌파 연동을 유지한다.
- 보유 카드에만 레벨·돌파·스킬·특성을 표시한다. 스킬은 `1/1/1/1/1/1`, 특성은 `0/12/5`처럼 각각 한 줄로 표시한다. 미보유 카드는 썸네일과 이름만 남긴다.
- 스킬 순서는 광기 폭발·타격·방어·각성·스킬 1·스킬 2, 특성 순서는 영혼 단련·광기의 징조·내재 영격이다. 한국어 항목명은 카드에서 제거하고 접근성 이름과 마우스 안내에 유지한다.
- 한정은 기존 분류 데이터의 망각편/성신편 ID 합집합으로 판정하며 내재 영격은 사용자 지시에 따라 5로 고정한다. 원본 성장 JSON을 수정하지 않고 보유 모델에서 정규화한다.
- 돌파는 ScareCrow와 동일하게 다이아 3개까지 점등한 뒤 강화 숫자 1–12를 붙인다. 예: 7단계는 다이아 3개+4, 15단계는 다이아 3개+최대 이미지다. 돌파 증감과 성장 편집은 유지한다.

- 통상/망각편/성신편·역할·명륜 등급 필터와 별칭/초성 검색을 제공한다.
- 선택/해제는 현재 검색 결과에만 적용하고 버튼 이름으로 범위를 알린다.
