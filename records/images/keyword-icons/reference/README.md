## 공용 특수 아이콘을 쓰는 항목

`special.png`를 공유한다.

- 소모, 유지, 발견, 준비
- 관통 피해, 촉수 피해, 영지 각성
- 영감, 여파, 포식, 배아 융합
- 초차원 공간
- 명계, 공명, 인지 착란, 제의, 의식, 허무, 워프

## 이번 요청에서 확인한 키워드

- 회귀와 음엔트로피는 서로 다른 전용 아이콘을 사용하며, 두 키워드의 글자색은 흰색이다.
- 공허는 픽맨의 `그림자 모사` 설명에 쓰인 전용 `void.png` 아이콘을 사용한다.
- 허무는 공용 `special.png` 아이콘을 사용한다.
- 사냥과 집단 사냥은 `group-hunt.png`를 공유한다.
